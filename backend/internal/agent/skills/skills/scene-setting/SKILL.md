# 场景设定图

## 做法
1. 按剧本场次归并出主要场景（同一地点不同时间算不同设定：白天和夜晚各一张）。每个场景一个图片节点，标题「场景名 时间」，放进「场景」组。
2. 提示词模板：
   `{场景名}空镜，无人物，{空间：室内外、大小、布局、关键物件的位置}；{时间与天气}；{主光源与色调}；{氛围词}；{风格词，与全片一致}；{画幅}。`
3. 写清**空间关系**：门在哪、窗在哪、主要家具的相对位置。后面不同镜头要在同一个空间里换机位，这些信息决定它们像不像同一个地方。
4. 光线要具体：霓虹灯的颜色、窗外光的方向、是否下雨有水渍反光。

## 一致性要点
- 同一场景的描述在各镜头里逐字复用关键物件和光线词。
- 需要不同机位时，在设定图的基础上改提示词里的视角，而不是重写场景。
- 之后的关键帧节点把对应场景图连进去作为参考。
