# 关键帧提示词

关键帧是镜头里最有代表性的一帧，之后会作为图生视频的首帧。

## 结构（按顺序写，一段话，中文即可）
`景别与机位，构图 + 主体（谁、在哪、什么姿态和表情）+ 动作瞬间 + 环境与前后景 + 光线与色调 + 风格与画幅`

示例：
`近景，略微仰拍，三分法构图。参考图中的女孩站在便利店门口，右手撑着透明雨伞，微微侧头看向店内，神情犹豫。雨夜街道，湿润地面反射霓虹灯，背景虚化。冷蓝色主光加暖黄色店内光，电影感，16:9。`

## 要点
- 画**一个瞬间**，不要写连续动作；动作留给视频提示词。
- 人物用「参考图中的……」指向已连线的角色图，不要重新描述外貌（会和参考图打架）；场景同理。
- 景别、机位、光线、风格这四项缺一项就容易跑偏，宁可写全。
- 画幅与全片一致，写在末尾或放进节点参数。
- 避免否定句和互相矛盾的词（又特写又全景）；避免大段文字渲染，画面里要出现的字最多一两个词并写明内容。
- 同一镜头需要备选时，多建几个节点，每个节点只改一两个变量（机位或光线），方便用户比较。

## 提示词优化模式
只改提示词、不动别的：保留用户原意，补上缺的四项，删掉矛盾和空话，并简短说明改了什么。
