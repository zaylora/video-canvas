# 角色三视图参考

目的：先给每个主要角色生成一张**固定的参考图**，之后所有镜头的关键帧都把它连进去当参考，人物才不会每个镜头长得不一样。

## 做法
1. 列出剧本里有戏份的角色（路人不用）。每个角色一个图片节点，标题「角色名 三视图」，放进「角色」组。
2. 提示词模板（按需改写，中文即可）：
   `角色设定图，同一个人的正面、侧面、背面三视图并排，全身，站姿自然，纯色浅灰背景，平光，无投影。{外貌：年龄、性别、脸型、发型发色、体型}；{服装：款式、颜色、材质、配饰}；{风格词，与全片一致}。`
3. 外貌和服装写**具体、可画出来**的细节：发色、衣服颜色和款式、标志性配饰；不要写「帅气」「气质出众」这类无法画出来的词。
4. 用户没给外貌时，先根据剧本补一版并展示给用户，确认后再申请生成，不要擅自定下来。

## 一致性要点
- 同一角色的外貌描述在所有节点里**逐字复用**，不要每次换说法。
- 全片风格词（画风、色调、画幅）统一，写进每个角色节点。
- 之后的关键帧节点必须连上对应角色的三视图节点，并在提示词里写明「参考图中的角色」。
- 角色改变造型（换装、受伤）要另建一个节点，不覆盖原图。
