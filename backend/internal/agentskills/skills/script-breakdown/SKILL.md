# 剧本拆镜

## 先弄清楚（缺什么问什么，用 ask_user，不要猜）
- 画幅（16:9 / 9:16 / 1:1）和整体风格（写实、动画、水墨……）；它们会决定整批生成是否作废。
- 总时长或镜头数的大致范围。没有说就按每个镜头 3 到 6 秒、整片 8 到 15 个镜头起步。

## 拆法
1. 先通读剧本，按**场次**（地点或时间变化）分段，再在每个场次里按**画面变化**拆镜头：人物位置、景别、视线方向或情绪变了就是新镜头。
2. 每个镜头写成一行：镜号｜景别｜机位与运镜｜画面（谁在哪、做什么）｜台词或旁白｜时长（秒）。
3. 景别在远景、全景、中景、近景、特写之间有节奏地切换；连续三个同景别通常说明拆得太懒。
4. 对白镜头用正反打或过肩；动作镜头保持动作的连续性（出画方向与入画方向一致）。
5. 一个镜头只讲一件事，只有一个主要动作；视频模型一个镜头里塞多个动作会失败。

## 落到画布
- 每个镜头一个组，组名「镜号 景别」，例如「03 近景」；组里放：镜头文本节点（画面和台词）→ 关键帧图片节点 → 视频节点，并按顺序连线。
- 角色和场景的参考图在镜头之外单独成组，连到各镜头的关键帧上，保证人物和场景一致（见 character-turnaround、scene-setting）。
- 镜头文本节点里保留镜号、景别、运镜、时长，后面写关键帧和视频提示词时直接引用它。
- 搭好后用 canvas_arrange 把各镜头组排整齐。

## 不要
- 不要改写用户的剧情和台词；觉得有问题就问。
- 不要在用户没确认拆分方案前就批量建图片和视频节点：先 plan_update 展示拆分，再动手。
