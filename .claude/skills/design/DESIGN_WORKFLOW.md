# video-canvas 设计 skill

路径：`.agents/skills/design/skill.md`

这个 skill 用来处理“我想给 video-canvas 做一个设计，但还没有清晰方案”的任务。它会：

1. 阅读项目代码、接口、数据结构和约束。
2. 根据设计主题调研 3–6 个相关的主流方案。
3. 通过 `grill-me` 的逐题访谈，收敛目标、优先级、交互和 MVP 范围。
4. 输出一份带证据、比较、取舍和工程影响的 Markdown 设计文档。

当前项目基线包括：Go/Gin/GORM/PostgreSQL/Redis 后端、用户隔离的画布项目、JSONB 画布 payload、`revision` 乐观锁，以及预留的节点、连线、对话、导演分镜、时间线、外观和视口字段。skill 每次运行都会重新检查代码，以当前实现为准。

## 使用方式

可以直接描述想做的设计，例如：

- “我想设计画布的节点编辑体验，但不知道怎么组织界面。”
- “帮我设计导演分镜和时间线之间的联动。”
- “我想给 AI 生成结果设计回填画布的流程。”

如果希望指定输出路径，直接在请求中给出；否则默认放到 `docs/design/<短名称>.md`。

## 文档特点

- 项目事实、外部调研、用户回答和设计提案分开记录。
- 每个推荐都有比较维度和取舍理由。
- 会覆盖空、加载、保存失败、版本冲突、生成失败和恢复等状态。
- 会说明对现有 JSON payload、API、`revision` 和后端分层的影响，但不会自行修改代码。
