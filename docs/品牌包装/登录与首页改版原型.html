    登录页与首页改版：一句话生成的「梦想感」

    设计面：登录页、首页（创作 / 对话 / 资产）、后台新增「登录页展示」。日期 2026-10-08。本页和原型放在同一个文件里，品牌定位与商业化的整体分析见同目录的 品牌与商业化分析。

    1. 问题和目标

    • 登录页左半边是静态的紫蓝渐变和一句文案，看不到「AI 生成出来的东西」，也就感受不到「一句话就能做出这样的画面」。
    • 首页只有一个禁用的输入框和最近画布，登录后不知道从哪开始；生成出来的东西散落在各个画布里，没有统一的地方回看。
    • 目标：第一眼看到真实的生成作品在播放；每个作品都标出「生成它的那句话」，把「输入一句话 → 得到这个画面」的因果直接摆在眼前；看到喜欢的可以一键「做同款」。
    • 转化目标：登录页只负责「看到 → 想做 → 注册」，不在登录前写创意；看中某个作品点「做同款」，它的提示词会在登录后带进首页，不丢失。

    2. 已定决定（访谈）

    1. 背景形态：全屏单镜头轮换。一次只播一个作品，到时间后交叉溶解到下一个，画面底部显示「生成它的那句话」。
    2. 登录页：全屏视频 + 一个「开始创作」按钮。正中是大标题、一句说明和按钮，不放输入框和快捷 chips（一句话输入只在登录后的首页出现）；点「开始创作」或「注册」右侧滑出注册卡片，点「登录」滑出登录卡片；点字幕里的「做同款」也滑出卡片，并把这条提示词带进首页。
    3. 首页：不放背景视频，参照即梦的「创作」页。问候语 + 「生成 / 画布」切换 + 输入卡片 + 技能 + 最近上新。
    4. 侧栏：创作 / 探索 / 资产，不做「主体」；下面两组最近记录「对话」「画布」。探索（作品广场）暂时置灰。
    5. 生成 tab：输入卡片带参考上传、模式（Agent / 图片 / 视频 / 音频）、模型（默认自动）、技能、@ 引用资产。提交后进入对话页：Agent 模式新开一段对话；直接出图/视频/音频归到置顶的「默认创作」。
    6. 画布 tab：新建画布、最近一张画布、两个模板，下面一行「一句话新建画布」，提交后新建画布并交给 Agent 拆分镜。
    7. 对话页：生成记录按日期分组，每条显示参考图、模式 · 模型 · 时长 · 清晰度、提示词、结果，以及「重新编辑 / 再次生成 / 更多」；Agent 记录多一段回复和「生成 N 段视频 / 在画布中打开」。输入卡片固定在底部。
    8. 资产页：「生成历史 / 画布」切换；生成历史按图片 / 视频 / 音频 / 文档过滤，另有筛选、时间、排序；没有内容时显示镜间光空状态。
    9. 片单来源：后台可配。新增「系统设置 → 登录页展示」，只给登录页背景轮播用。
    10. 品牌：定名连镜。主 Slogan「意义，在镜头之间。」放在登录页顶栏品牌名旁（767px 以下隐藏）；功能 Slogan「从一句话，到一部片。」做登录页大标题；Logo 用镜间光（两个镜头之间透出一道琥珀光），侧栏、后台这类 24px 及以下的位置换小尺寸版。光束浅底用深琥珀，深底和视频上用亮琥珀，对应新增 token --brand-amber / --brand-amber-deep / --la。

    默认决定（未单独问，按推荐项定，有异议直接改）

    • 输入卡片只有一份：在创作页和对话页之间移动，模式和没发出去的草稿跟着走。Enter 发送，Shift+Enter 换行。
    • 「最近上新」先写死三张（精选作品 / 新功能 / 模型上新），后续再考虑放进后台配置。
    • 后台没开 Agent 时，模式菜单里隐藏「Agent 模式」，默认选「图片生成」；画布 tab 的一句话输入改为在新画布里落一个文本节点。
    • 登录后带入（只来自「做同款」）：这句提示词存进 sessionStorage（不放 URL，免得带进历史记录和日志）。首页切到「生成」tab，填进输入卡片并聚焦，不自动提交，由用户确认后再发。
    • 每条默认播 7 秒，后台可调 4–15 秒；视频静音、循环、playsinline。
    • 一直提供暂停按钮（自动轮换超过 5 秒必须能暂停，见 WCAG 2.2.2）；标签页切到后台时自动暂停。
    • 登录卡片跟随主题（浅色为白卡），压在暗色视频上对比最清楚；视频上的文字和控件统一用新增的 --on-media / --glass token，深浅主题取同一组值。
    • 后台给体积提示：单条超过 15 MB 标黄「首屏会变慢」；竖屏素材标黄「横屏会被裁切」。只提示，不阻止。
    变更：原为「轮播自动播放：常驻循环动画违反动效规则，改成手动切换」（docs/design/首页/首页.md 第 2 节）。现改为背景视频自动轮换，并加上这些约束：始终可以暂停；后台标签页和离开视口时停止；系统开启「减少动态效果」时只显示封面、不自动切换。

    6. 状态表

    状态表现
    视频加载中先显示封面；进度暂停计时，最多等 4 秒，超时按「只有封面」继续计时。
    视频加载失败停在封面，照常计时切换（原型：控制条「视频失败」）。
    封面也加载失败显示按条目色相生成的静态渐变。
    片单为空 / 后台关闭该页播放默认静态渐变背景，隐藏字幕和进度；页面其他功能不受影响。
    只有 1 条循环播放，隐藏进度条，保留暂停按钮。
    减少动态效果只显示封面，不自动切换，不逐字打出提示词；点进度段仍可手动切换，全部用淡入淡出。
    省流量（navigator.connection.saveData）后台开关打开时只显示封面。
    标签页隐藏暂停视频和计时，回来后从原处继续。
    用户手动暂停按钮变成播放图标，视频和计时都停住。
    登录中 / 失败按钮转圈并禁用；失败时在表单内显示错误提示，不清空已填的内容。
    资产为空 / 搜索无结果镜间光空状态 +「暂无相关资产」，提示去创作或换个关键词。
    对话里没有记录空状态，输入卡片照常可用。
    生成失败结果位显示失败原因和「重试」，积分已退回时一起说明（原型未做）。
    注册关闭隐藏顶栏「免费注册」和卡片里的分段切换。
    窄屏 <768px登录卡片变成底部抽屉；字幕和进度上下堆叠；首页侧栏变成抽屉；技能和最近上新横向滑动；输入卡片工具条只保留模式文字，其余只显示图标。
    深 / 浅主题登录页视频区域两套主题一致（本来就是暗的）；登录卡片、首页、后台跟随主题；镜间光的琥珀色浅底用深琥珀。

    10. 原型说明

    • 背景视频是 Mixkit 的免费素材，只用来占位，配的提示词和模型标签是示意。正式版播放后台配置的真实生成作品。
    • 后台的增删、排序、开关、时长改动，会实时同步到原型里的登录页。
    • 首页的对话记录、资产、最近上新都是示意数据；提交后的生成用定时器模拟进度。
