    登录页与首页改版：一句话生成的「梦想感」

    设计面：登录页、首页 Hero、后台新增「首页展示」。日期 2026-10-08。本页和原型放在同一个文件里，品牌定位与商业化的整体分析见同目录的 品牌与商业化分析。

    1. 问题和目标

    • 登录页左半边是静态的紫蓝渐变和一句文案，首页 Hero 是点阵背景。都看不到「AI 生成出来的东西」，也就感受不到「一句话就能做出这样的画面」。
    • 目标：第一眼看到真实的生成作品在播放；每个作品都标出「生成它的那句话」，把「输入一句话 → 得到这个画面」的因果直接摆在眼前；看到喜欢的可以一键「做同款」。
    • 转化目标：访客先写创意、再登录。写下的这句话会在登录后带进首页，不丢失。

    2. 已定决定（访谈）

    1. 背景形态：全屏单镜头轮换。一次只播一个作品，到时间后交叉溶解到下一个，画面底部显示「生成它的那句话」。
    2. 登录页：全屏视频 + 先写创意再登录。正中是大标题和输入框；点生成或「登录」，右侧滑出登录卡片；登录后这句话带进首页。
    3. 首页：Hero 面板内铺满视频。保留侧栏和圆角大面板；最近画布放在面板下方，照常可用。
    4. 片单来源：后台可配。新增「系统设置 → 首页展示」，登录页和首页共用同一份片单。

    默认决定（未单独问，按推荐项定，有异议直接改）

    • 首页提交行为：新建画布，把这句话交给画布 Agent 拆分镜；没开 Agent 时，在新画布里落一个文本节点。原来的「发送按钮禁用 + 即将上线」不再保留。
    • 登录后带入：这句话存进 sessionStorage（不放 URL，免得带进历史记录和日志）。首页读取后填进输入框并聚焦，不自动提交，由用户确认后再发。
    • 每条默认播 7 秒，后台可调 4–15 秒；视频静音、循环、playsinline。
    • 一直提供暂停按钮（自动轮换超过 5 秒必须能暂停，见 WCAG 2.2.2）；标签页切到后台、首页 Hero 滚出视口时自动暂停。
    • 登录卡片跟随主题（浅色为白卡），压在暗色视频上对比最清楚；视频上的文字和控件统一用新增的 --on-media / --glass token，深浅主题取同一组值。
    • 后台给体积提示：单条超过 15 MB 标黄「首屏会变慢」；竖屏素材标黄「横屏会被裁切」。只提示，不阻止。
    • 品牌名暂时沿用 Video Canvas，等定名后统一替换。
    变更：原为「轮播自动播放：常驻循环动画违反动效规则，改成手动切换」（docs/design/首页/首页.md 第 2 节）。现改为背景视频自动轮换，并加上这些约束：始终可以暂停；后台标签页和离开视口时停止；系统开启「减少动态效果」时只显示封面、不自动切换。

    4. 控件说明

    控件位置 / 尺寸状态与交互
    背景舞台登录页满屏；首页 Hero 面板内 clamp(480px, 62vh, 640px)，圆角 28px双层 <video> 交替：先显示封面，首帧可播后视频淡入盖住封面；到时长后两层交叉溶解。下一条提前预加载。
    遮罩上下线性渐变 + 中心椭圆压暗保证白字在任何画面上可读，新增 token --scrim-edge、--scrim-center。
    一句话输入框高 60px，圆角 20px，最大宽 720px；玻璃材质空时发送按钮禁用；Enter 提交；聚焦时上移 1px、加阴影。「做同款」或 chip 填入时外圈闪一下 ring。
    快捷 chips输入框下方，窄屏横向滚动点击填入模板文案并聚焦输入框。
    字幕左下角，最大宽 520px（首页为面板一半）标签「这段画面，由一句话生成」+ 带引号的提示词 + 模型 · 作者 +「做同款」。切条时淡入，然后逐字打出提示词。
    做同款字幕行内，高 28px 的玻璃胶囊把当前作品的提示词填进输入框并聚焦，不自动提交。
    进度条右下角，每条一段 26×2px，hover 时变 4px 粗点某一段直接跳到那条；只有 1 条时隐藏。旁边显示「1 / 6」和暂停/播放按钮。
    登录卡片右侧悬浮，宽 400，上下各留 16px；窄屏变成底部抽屉带入创意时顶部显示「登录后立即开始生成」并引用这句话，可以 ✕ 掉。登录/注册用分段控件切换（注册关闭时隐藏）。Esc、✕、点遮罩都能关闭，关闭后焦点回到输入框。
    后台作品列表左栏卡片，每行：拖动手柄、16:9 缩略图（hover 播放）、提示词两行、标签、启用开关、编辑、移除拖动排序（实现用 motion 的 Reorder）；移除后 toast 里可以撤销；关闭启用的行半透明显示。
    实时预览右栏，16:10 迷你舞台和前台用同一个播放器，可以切登录页/首页两种外观；只播启用的条目。
    编辑抽屉右侧 460px视频预览、提示词（≤80 字，必填）、模型标签、起始秒数、封面（自动截帧/上传）、启用。
    从素材库添加居中对话框，卡片网格多选；已在片单里的置灰；提示词和模型从生成记录自动带入。

    6. 状态表

    状态表现
    视频加载中先显示封面；进度暂停计时，最多等 4 秒，超时按「只有封面」继续计时。
    视频加载失败停在封面，照常计时切换（原型：控制条「视频失败」）。
    封面也加载失败显示按条目色相生成的静态渐变。
    片单为空 / 后台关闭该页播放默认静态渐变背景，隐藏字幕和进度；页面其他功能不受影响。
    只有 1 条循环播放，隐藏进度条，保留暂停按钮。
    减少动态效果只显示封面，不自动切换，不逐字打出提示词；点进度段仍可手动切换，全部用淡入淡出。
    省流量（navigator.connection.saveData）后台开关打开时只显示封面。
    标签页隐藏 / Hero 滚出视口暂停视频和计时，回来后从原处继续。
    用户手动暂停按钮变成播放图标，视频和计时都停住。
    登录中 / 失败按钮转圈并禁用；失败时在表单内显示错误提示，不清空已填的内容。
    注册关闭隐藏顶栏「免费注册」和卡片里的分段切换。
    窄屏 <768px登录卡片变成底部抽屉；chips 横向滚动；字幕和进度上下堆叠；首页侧栏变成抽屉。
    深 / 浅主题视频区域两套主题一致（本来就是暗的）；登录卡片、首页其余部分、后台跟随主题。

    9. 依赖

    不装新依赖。拖动排序用已有 motion 的 Reorder；播放器用原生 <video>，几十行能写清楚，不引入轮播库。

    10. 原型说明

    • 背景视频是 Mixkit 的免费素材，只用来占位，配的提示词和模型标签是示意。正式版播放后台配置的真实生成作品。
    • 后台的增删、排序、开关、时长改动，会实时同步到原型里的登录页和首页。
