01

渠道模型列表：已启用的排前面

后台后端
现状
  • 列表在 Go 内存里排序（backend/internal/service/ai_catalog_list.go 约 326–340 行）：渠道顺序 → sort → key，不看启用状态。
  • 拖动保存时把整个渠道重写成 sort = 10, 20, 30…；启停开关只改 enabled，行不会移动。
方案
  • 排序改为：渠道顺序 → 已启用在前 → sort → key。启用组和未启用组各自保留手动拖动的顺序。
  • 按 enabled 判断，不按「在线」健康状态（健康状态会自己变，列表会跳）。
  • 拖动只在同组内有效，跨组拖动在前端拦下并回弹；保存接口和后端校验不变。
  • 切换启用开关后，行移到对应分组，这是预期行为。
测试
  • 改 ai_catalog_list_test.go「顺序是用户看到的顺序」的期望，新增「启用在前、组内按 sort」用例。
  • 把跨组判断抽成纯函数放到 web/src/utils/admin/，补单测。
02

短剧加载动画播完重来

短剧根因已确认
根因
  • web/src/pages/drama/workspace/index.tsx 第 118 行：数据没到时直接返回加载层；数据到了以后，加载层换到 Fragment 的最后（第 192 行）。位置变了，React 卸载旧加载层、挂一个新的，动画从头播放，900ms 最短展示时间也重新计时。
  • 次要：退场时整条 animation 被替换，logo 从对焦循环的当前位置跳回原位再退场，有一帧跳变（web/src/index.css 666–673 行）。
方案
  • 两种状态都返回同一结构 <>{value && 工作台}{loader}</>，加载层位置不变，不会重挂。
  • 退场动画放到 logo 外层的包裹元素上，内层继续对焦循环，两层 transform 叠加，去掉跳变。
  • 动画设计本身不改。
测试
  • 数据从无到有时，加载层 DOM 节点是同一个，没有被重新挂载。
03

角色卡详情：保留历次 AI 生成的音频

画布 / 短剧后端
现状
  • 每个角色节点只有一个 voiceTaskId 槽位。生成成功后，音频绑成当前音色，任务 id 被清掉，新结果直接覆盖旧的，没有历史记录。
  • 声音任务的 node_id 是 voice:{角色节点id}，后端表里有这一列，但查询接口只支持按任务 id 查和查进行中任务。
  • 模型选择和错误信息只存在组件内存里，切换工序时节点卸载就丢了。
方案
  • 后端：GET /generation-tasks 增加 node_id 查询，必须同时带 canvas_project_id。只查当前用户的非测试任务，按创建时间倒序，最多 20 条。按 router → handler → service → repository 分层实现。
  • 前端：「AI 生成声音」下加「生成记录」列表。每条显示提示词摘要、模型、时间、状态；成功的可以试听、可以「设为音色」，当前音色会标出来；失败的显示原因。
  • 打开详情时拉一次记录，新任务完成后插到列表顶部。
  • 模型选择存进节点数据，切工序回来不丢。
  • 顺带核实：撤销字段里有 voiceTaskId 没有 character，撤销可能把音色退回去而任务 id 还在。写测试确认，确有问题一并修。
测试
  • 后端 repository / service / handler 补按 node_id 查询的用例：只返回本人的、非测试的，按时间倒序，有条数上限，缺 canvas_project_id 时返回参数错误。
  • 前端补「任务转列表项」「设为音色」的纯函数测试。
04

分集栏固定成一条公共栏

短剧方案已确认
现状
  • 剧本、资产管理、片场、成片四个页签用的是同一个分集栏组件，但里面的内容会变：只有剧本页顶上有「大纲」「人物」，只有资产页有「全集」，所以集号列表会上下跳。
  • 总览页不显示分集栏，切进切出时主内容会左右平移 78px。
方案
  • 所有页签都显示「大纲」「人物」；在非剧本页点击，跳到剧本页并打开对应文档。
  • 「全集」固定占位，只在资产管理页可点，其他页签显示为置灰禁用，悬停提示「仅资产管理可按全集筛选」。
  • 总览页也显示分集栏，点某一集跳到该集的剧本页。
  • 「新增一集」在列表最底部，不影响上面各项的位置，仍只在剧本页显示。标题统一为「分集」。
测试
  • episode-rail.test.tsx：各页签顶部条目一致；非资产页「全集」处于禁用状态；总览页显示分集栏。
05

主侧边栏横向溢出

首页
根因
  • 对话和画布列表在纵向滚动容器里（app-sidebar.tsx:129），这个容器的横向也会变成可滚动。
  • 列表容器 grid gap-0.5（sidebar-list.tsx:25）没有定义列宽，长标题不换行，把整列撑宽，省略号截断没生效，于是底部出现横向滚动条。这是读代码得出的推断，动手前先在本地复现。
方案
  • 列表容器改成 grid-cols-[minmax(0,1fr)]，列表项外层加 min-w-0，长标题正常显示省略号。
  • 滚动容器加 overflow-x-hidden 兜底；侧栏保持 15rem 固定宽度。
测试
  • jsdom 测不了真实布局，用 class 断言防止回归。

人物传记改成卡片

短剧方案已确认
现状
  • project-doc.tsx 把 AI 写的人物 Markdown 放进富文本编辑器显示。
  • 常见结构：分组（主要人物）→ 一级列表是人名，可带「（外号：…）」→ 二级列表是 **身份**：…、动机、能力/根基、关系网络、角色弧线。
方案
  • 新增 web/src/utils/drama/parse-characters.ts，把 Markdown 解析成人物列表：每个人物有分组、名字、外号和若干字段。
  • 不认识的字段名照常显示，没有字段名的行放进「其他」，内容一条都不丢。
  • 所有人物用同一种卡片：卡片头是名字、外号和分组标签，下面逐项列出字段，字段名和内容分开排版，长内容可以展开。
  • 卡片只用来查看，保留「编辑原文」入口切回现在的富文本编辑器。
  • 如果一个人物都解析不出来，直接显示原来的富文本，不出现空白页。
测试
  • 覆盖截图里的格式、带外号、多分组、未知字段、无字段名的行、空字符串、非列表 Markdown（回退）。

08

比例图标形状不准

画布 / 后台
现状
  • video-param-panel.tsx 的比例图标是最长边 16px、1.5px 边框、3px 圆角的方块。21:9 高约 7px，扣掉上下边框只剩约 4px，再加上圆角，看起来像胶囊，比例失真。Auto 和 1:1 是同样大小的方框。
  • 短剧的比例选择器（pickers.tsx:231）另有一份 18px 的画法，两处不一致。
  • 后台和画布节点的生成面板用的是同一个网格，改一次两处都生效。
方案
  • 抽一个共用的 SVG 比例图标，按真实宽高比画矩形，描边画在内侧，圆角按短边按比例取，最大 2px。两处都改用它。
  • 所有比例放进同一尺寸的外框里居中，方便直接对比形状。
  • Auto 换一个和 1:1 不同的图形，比如四角括号。
  • 不支持的选项按通用规则置灰禁用。
测试
  • 16:9、21:9、9:16 输出的矩形宽高比与标称值一致（误差小于 1%）；Auto 和 1:1 的图形不同。

验证与默认假设

验证

  • 后端（第 1、3 条）：cd backend && go test ./internal/tests/...。
  • 不做 Playwright 端到端测试。第 2、4、5、8 条是视觉问题，改完需要人工在浏览器里看一眼。
假设

  • 第 4 条：在总览页点某一集，跳到该集的剧本页。
  • 第 5 条：根因是读代码推断的，动手前先在本地复现。
  • 置灰规则：理解为针对分集栏「全集」这类不可点项，并推广到本次涉及的所有不可点选项。
