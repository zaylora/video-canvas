节点内容加载占位 · 三种方案

图片缩略图、原图、视频封面还没出来时，节点预览框里显示什么。点「重新加载」看每种方案从占位到内容的过渡。

A · 扫光 shimmer（推荐）

灰底上一道柔和的浅色光带从左到右缓缓扫过，1.6s 一轮。最像“正在加载”，又不会和「生成中」的呼吸骨架混淆。

图片节点

0:15

视频节点（封面）

B · 呼吸渐变

整块灰色在深浅之间缓缓明暗，2s 一轮，更安静。缺点：和「生成中」的 animate-pulse 骨架几乎一样，用户分不清是在等图还是在等生成。

图片节点

0:15

视频节点（封面）

C · 静态灰底 + 内容淡入

占位不动，就是一块灰；内容到了从灰底淡入。最克制，画布上节点多时零开销。缺点：等得久会像卡死。

图片节点

0:15

视频节点（封面）

  • 防闪烁：占位层要等 150ms 才出现。把耗时拖到 100ms 以下再点「重新加载」，会看到内容直接淡入、没有灰块一闪而过（命中缓存的场景）。
  • 过渡：内容到了以后，内容层 180ms 淡入盖住占位层，占位层 126ms 淡出，不会露出空白。
  • 视频：占位到封面到了为止；播放按钮和时长角标跟着封面一起淡入，不单独先出现。点击播放后的加载环沿用 6.11，不变。
  • 减少动态效果：勾上后光带和呼吸都停掉，只剩一块静灰底和淡入淡出。
