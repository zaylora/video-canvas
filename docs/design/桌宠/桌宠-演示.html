画布桌宠「小镜」

把右下角的助手入口，换成一只会动的小黑猫

桌宠「小镜」替代画布右下角的 Agent 胶囊按钮。它用动作反映助手和生成任务的状态，可以拖到画布任意位置，结果回来时会冒泡告诉你，还接管画布页的 toast，同一件事只说一遍。一期只在画布页、只有一只内置形象、不会自己走动；换皮肤和用户自己生成桌宠放在二期。

阅读说明。项目现状来自 2026-11-06 读取的代码，文件路径见 Markdown §2.1。外部调研由子代理检索，没有逐条复核。原型里的黑猫是 SVG 示意，真实实现是透明雪碧图。本设计尚未实现。对应文档：docs/design/桌宠/桌宠.md。
核实度图例： 已核对代码 / 官方页面 调研检索，未逐条复核 未验证 · 需实测 提案

一件事从发生到被你看见

助手和生成任务的状态，怎样变成桌宠的动作和气泡。

状态源ctl.busy / pending、任务库 WS 推送、画布提醒 已有
petMood()按优先级挑一行动作：拖动 > 反应 > 等审批 > 运行 > 生成中 > 睡 > 打招呼 > 待机 提案
气泡队列四类来源、一次显示一个、2 秒内同类合并 提案
雪碧图 + 气泡CSS 按帧切换，React 只在换动作时渲染一次
设计：「挑哪个动作」和「说什么」拆成两个纯函数，能单独测试；渲染层只认结果，每一帧都不经过 JS，这是性能硬约束要求的。
桌宠不在的时候（永远可用的退路）：图集还没加载完、加载失败、用户选了「隐藏」或者窄屏不支持时，右下角退回现在的「小镜」胶囊按钮，提醒退回 toast，功能一个不少。

桌宠有三档

右键桌宠切换。档位决定它会主动说多少话。

活泼
默认

全部动作和全部冒泡，包括彩蛋（30 分钟最多 1 条）。空闲 10 分钟后会睡着。

安静
只说正事

助手、生成结果、系统提醒照常；不打招呼、没有彩蛋，空闲时也不睡。

隐藏
等于今天

回到胶囊按钮和 toast，行为和今天完全一致。右键胶囊可以把桌宠找回来。

要兼顾三件事：性能、和你选的位图形象一致、二期能让用户自动生成。

你提交了 6 个视频，然后去干别的，会发生什么

从提交到结果回来的完整路径，以及一个需要提前说清的边界。

  1. 小镜进入「盯着看」画布里有未结束的生成任务，播 review 行；不说话。
  2. 前 3 个在 2 秒内先后完成合并成一个气泡「3 个视频好了」，小镜跳一下。
  3. 点一下气泡画布 fitView 到这 3 个节点，节点闪一下边框。
  4. 1 个失败小镜垂头丧气，气泡「有 1 个没生成出来，积分退回了：{原因}」，停留 6 秒。
  5. 全部结束回到待机。原来那条 toast 不再弹出。
边界：只对本次打开画布之后新到的结果说话。
  • 刷新页面、断线重连后对账回来的旧成功，不会再庆祝一次。
  • 页面在后台时，消息照常排队；回到前台只显示一条最重要的，系统通知仍由原来的逻辑发。
  • 冲突弹窗这类必须处理的弹窗不交给桌宠。

上线时要告知用户：画布页的 toast 改由小镜来说；不喜欢可以切到「隐藏」，一切回到原样。

状态怎么挑动作，气泡怎么排队

左边勾选当前有哪些状态，右边实时显示 petMood() 会选哪一行动作，命中的是优先级列表里的哪一条。下面是这一行的帧时长生成的 CSS。规则是提案，帧时长来自 hatch-pet 规范。

    优先级从高到低：拖动永远最高（你手里抓着它）；一次性反应会打断持续状态，播完一轮再回来；「等你」比「它在忙」更重要。
    这一行生成的 keyframes（step-end，每帧时长可以不同） 
    
              
    CSS 的 steps() 只能做等长帧；hatch-pet 每行最后一帧会停得更久，所以要在运行时按帧时长算出百分比。
    
            
    
          
    
        
    

        
    
          
    气泡的四类来源和优先级
    
          
    一次只显示一个；高优先级的会顶掉低优先级的，被顶掉的（彩蛋除外）放回队首。
    
          
    
            
    
              
    优先级类别什么时候停留点气泡
    
              
                
    1 审批助手浮窗收起时出现待审批不自动消失，直到处理完打开浮窗
    
                
    2 错误助手 / 生成 / 系统助手出错、生成失败、保存失败、积分不足6 秒打开浮窗 / 定位节点 / 去充值
    
                
    3 结果助手 / 生成一轮跑完（浮窗收起时）；本画布生成成功（2 秒内合并）4–5 秒打开浮窗 / 定位节点
    
                
    4 系统画布提醒原来那些画布 toast：上传结果、文字截断、取消退款等4 秒原 toast 有按钮的保留按钮
    
                
    5 彩蛋闲聊只在活泼档：当天第一次打开、睡醒、深夜4 秒—

    // web/src/utils/pet/mood.ts（提案）
export function petMood(s: MoodInput): { row: PetRow; loop: boolean } {
  if (s.dragging) return { row: s.dragDir > 0 ? "running-right" : s.dragDir < 0 ? "running-left" : "idle", loop: true };
  if (s.reaction) return { row: s.reaction === "celebrate" ? "jumping" : "failed", loop: false };
  if (s.pending) return { row: "waiting", loop: true };
  if (s.busy) return { row: "running", loop: true };
  if (s.runningTasks > 0) return { row: "review", loop: true };
  if (s.available === false || (s.mode === "lively" && s.idleMs >= 10 * 60_000)) return { row: "sleeping", loop: true };
  if (s.hovering && s.mode === "lively" && s.canGreet) return { row: "waving", loop: false };
  return { row: "idle", loop: true };
} // reducedMotion 由渲染层处理：只显示第 0 帧

// web/src/utils/pet/placement.ts（提案）
export function placePanel(pet: Rect, area: Size, want: Size, gap = 8, pad = 12) {
  const h = Math.min(want.h, area.h - 2 * pad), w = Math.min(want.w, area.w - 2 * pad);
  let side = pet.y - h - gap >= pad ? "top" : pet.y + pet.h + gap + h <= area.h - pad ? "bottom"
           : pet.x > area.w - (pet.x + pet.w) ? "left" : "right";
  let x = side === "left" ? pet.x - gap - w : side === "right" ? pet.x + pet.w + gap
        : pet.x + pet.w / 2 > area.w / 2 ? pet.x + pet.w - w : pet.x;
  let y = side === "top" ? pet.y - gap - h : side === "bottom" ? pet.y + pet.h + gap : pet.y + pet.h / 2 - h / 2;
  return { x: clamp(x, pad, area.w - pad - w), y: clamp(y, pad, area.h - pad - h), w, h, side };
}

// web/src/utils/pet/notice.ts（提案）
export function canvasNotice(kind, text, opts) {
  if (usePetStore.getState().active) usePetStore.getState().push({ kind: toBubbleKind(kind), text, ...opts });
  else toast[kind](text, { id: opts?.id, action: opts?.action && { label: opts.action.label, onClick: opts.action.run } });
}

    • 在左上角点开浮窗，浮窗从桌宠旁边弹出，并且完整显示在画布内。

    • 系统开启「减少动态效果」时显示静态帧；暗色主题下黑猫轮廓清晰；bash scripts/check.sh 通过。
