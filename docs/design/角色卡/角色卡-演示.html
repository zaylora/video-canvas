角色卡设计演示

角色卡：把形象和声音绑成一个可复用的角色

在资产页建一次角色卡，之后在任何画布里双击选卡、连一根线，人物形象当参考图、声音当参考音频，一起带进视频生成。修改角色卡一次，所有画布里引用它的节点跟着变。 这期不做文字转语音、音色克隆，声音就是一段已有的音频素材。

主线：一个角色怎么从创建走到出片

四步，前两步在「管理」，后两步在「使用」。

1 资产页建卡名称 + 主图 + 补充图 + 声音 + 设定
2 画布双击选卡弹出选择框，多选，落在双击处
3 连线展开形象 → 参考图片；声音 → 参考音频
4 提交生成按角色卡当前内容取素材
设计：角色卡只引用素材 ID，不复制文件；节点只存 characterId，所以「改一次全画布生效」。放弃了「节点存快照」，代价是旧画布的生成条件会随角色卡变化（已确认接受）。
回退，永远可用：目标模型不收参考音频 → 只带形象并提示「声音未生效」；角色卡被删 → 节点显示「已失效」，连线保留但不参与提交；素材被清理 → 对应部分灰显，其余照常。任何一种都不会阻断生成。

当我改了或删了一张角色卡，会发生什么

这是「实时引用」最需要提前说清的一件事。

  1. 在资产页改了林晚的声音保存成功后，角色卡缓存失效。
  2. 已打开的画布刷新节点节点上的名称、封面、试听立刻换成新的。
  3. 下一次生成取最新内容提交前强制刷新该角色卡，不会用旧图旧声音。
  4. 删除林晚所有引用它的画布节点变「已失效」，可重新选择或删除节点；素材文件不受影响。
边界：旧画布里已生成的结果不会变，但再次生成的条件会变。
  • 同一画布「重跑」同一个节点，可能得到和上次不同的形象或声音。
  • 没有版本回退；想保留旧形象，需要另建一张角色卡。
  • 删除前无法告诉你「有几个画布在用」：引用存在各画布内容里，后端不做反查。

交付时提前告知：改角色卡会影响所有引用它的画布。若反馈强烈，可启用「节点存快照」（已搁置的决定）。

可点击原型

数据在内存里，刷新复原。已预置「林晚」（有声音）和「陈默」（没声音）。推荐顺序：资产页点卡片编辑 → 切到画布 → 空白处双击选「角色卡」→ 拖节点右侧的 + 连到「视频生成」→ 发送。 想看失败：名称写 bad 保存失败、改成已有的名字会提示重复；把视频节点的模型切到「图生视频」看声音未生效和参考图截断；回资产页删掉已放上画布的角色卡看节点失效。

编辑弹框左图右文。形象是这张卡最重要的东西，给它最大的位置；补充图做成 4 个固定槽，一眼看出还能放几张。放弃了「一长串素材按钮」的选法。
选素材按种类过滤。选主图只看图片、选声音只看音频；已用的素材禁用并写原因（已是主图 / 已添加 / 已达上限），不隐藏。
节点长得像现有节点。名称在卡片上方、右侧 + 拖线，和图片 / 视频节点同一套外观；「声音未生效」挂在名称旁边，不遮封面。

核心：角色卡节点怎么展开成参考素材

这是唯一需要动绑定核心的地方：今天一个节点只能提供一种东西（PORT_OF_KIND），角色卡要同时给图片和音频。

// utils/tasks/capabilities.ts（提案）
PORTS_OF_KIND.character = ["image", "audio"]      // 多值端口，其余节点仍是单值

resolveBindings(caps, op, links, store):
  for link of links where link.sourceKind == "character":
    card = store.characters[link.characterId]
    if (!card) continue                            // 已失效：连线保留，不参与提交
    images.push(card.avatar, ...card.extras)       // 主图在前
    if (card.voice) audios.push(card.voice)
  // 目标当前方式不收 audios：丢弃并给出 voiceIgnored 提示（非阻断）
  // images 超过目标上限：按顺序截断并给出 truncatedFrom = N + 1

canLinkNodes(character, target):
  target 当前或可切换的方式收图片（或音频）即放行
opForLink(character, target):
  优先选能同时收图片和音频的方式（如「文生视频」→「全能参考」）

已确认的决定

  1. 节点 + @ 两者都要：节点可连线，提示词里也能 @角色名。
  2. 双击选「角色卡」弹出选择框：角色卡始终以资产页为唯一来源。
  3. 声音 = 一段参考音频素材：不新增 TTS、音色克隆、voice_id。
  4. 形象 = 1 张主图 + 可选多张补充图。
  5. 模型不支持参考音频：只用形象，节点上提示声音未生效，不阻断。
  6. 节点实时引用，跟随修改；删卡后节点失效。（已搁置：节点存快照 + 手动同步。）
  7. 设定文字：有，但只展示、不自动注入提示词。
  8. 分两期：一期管理页 + 节点 + 连线；二期 @。
  9. 仍待确认（二期前）：@ 的角色是否必须先放上画布（默认是）。
