这一版改了什么

  1. 过程收成一根细轨：活动行只剩「用时 + 动作图标」，你的回答挂在同一根轨上。
  2. 回答正文是唯一的大字号内容，节点名变成可点的引用 chip。
  3. 复制 / 改动 / 评价合成一行底栏；改动是可展开的胶囊。
  4. 计划条并进输入框顶部，不再悬空一行。
  5. 顶栏 5 个图标减到 4 个：标题本身就是历史入口。
  6. 颜色只剩黑白灰；琥珀色只给「需要你行动」：提问、审批、未完成。
  7. 发送按钮去掉渐变，改成前景色实心圆；运行中变停止，有输入时变「插话」。
