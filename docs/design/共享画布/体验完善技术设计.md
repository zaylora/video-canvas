# 共享画布体验完善技术设计

2026-11-26 · 本地实现与验收记录

产品规则和验收以[体验完善方案](体验完善方案.md)为准。沿用[一期接口、事务与鉴权边界](技术要点.md)。

## 渲染与权限

- 保留 `/canvas/:id/reader`、共享详情接口和媒体读取路径。读页与标准编辑路由接入同一个画布展示层，复用节点体、分组、连线、背景、控件和预览组件。已有所有者多标签页只读与共享查看分别配置权限，前者的接管动作只出现在所有者场景。
- `CanvasWorkspace`、`CanvasFlowSurface` 和 `WorkspaceChrome` 统一作者和接收方的画布布局、节点与连线注册、背景、小地图、缩放及统计。标准编辑会话挂载保存、任务回填、生成和 Agent。共享会话使用 `SharedCanvasScene`，按只读权限挂载素材灯箱、节点详情及分镜表，导演台复用 3D 视口来播放时间轴和切换机位。
- 查看历史结果、切换导演台镜头、拖动播放进度等交互状态保存在当前预览内。节点与文档模型保持原样，关闭预览直接释放该状态。以相同输入道具对比查看与编辑两端，权限相关控件单独断言。

## 共享数据与媒体

- 对照标准节点和边组件的实际读字段，审计 `ProjectShared`。用一份包含所有受支持节点类型的代表性已保存图，确认节点尺寸、组层级、端口、分镜、导演台场景和媒体字段能完整渲染。连线样式若由标准渲染层根据图推导，优先复用同一路径。由文档持久化的字段按明确类型加入允许列表。
- 图片、视频和角色节点的模型画幅与已保存参数推导值不同时，编辑器将实际采用的占位画幅保存为 `frameAspect`，共享页据此还原。旧存档缺少该字段时从已保存的参数取值。只有模型默认值且尚未重新保存的旧节点仍可能显示通用占位比例。
- 当前节点媒体、输出历史、分镜、导演台和参考素材统一走共享范围的媒体 URL。每次详情刷新签发媒体凭据，每次媒体请求复核授权及素材范围。媒体接口支持 `HEAD` 和单区间读取，供视频加载及跳播。
- 视频封面由同一媒体接口用 `?v=poster` 提供。服务端复核授权后读取标准画布使用的封面变体，返回限量图片数据，媒体凭据留在服务端。处理服务不可用时显示视频占位，原视频仍按原路径读取。
- 旧版角色卡在共享投影中按编辑器的兼容规则转成内嵌空角色，保留名称、主图和画布布局。分镜表与编辑器使用相同的分镜图来源规则。角色主图、补充图和导演台缩略图加载出错时显示节点级提示。
- 首次打开、`focus`、手动刷新和自动刷新共用加载器。自动刷新默认每 15 秒检查，可用滑杆调整为 1–60 秒。浏览器记住刷新模式和间隔。关闭自动刷新时移除定时检查和回焦监听，并取消进行中的自动请求。定时检查仅在页面可见且无进行中的请求时发出。调整间隔时保留当前请求和画面。续读携带当前 `revision`。相同版本只读取授权及版本号，返回 `{ "unchanged": true }` 并续签媒体凭据。版本变化时返回完整投影，并保留查看者视口。临时网络错误保留当前画面并显示重试状态。撤权清空文档与预览，切换画布或取消请求后丢弃旧响应。

## 列表与交付

- 个人列表使用所有者查询，共享列表使用 `canvas_viewers` 查询。进入作品页、回前台或手动刷新时重新获取当前列表，处理搜索和分页。用双账号已打开页面验证交付后可发现新作品。
- 发送副本和转移继续使用 `request_key`、源 `revision` 及接收方归属。复核接收方所有者能力，以及每类必需素材改写后是否可以播放、编辑和再次生成。转移沿用锁与 Agent 交付租约、同事务创建目标与退役原作的路径。源版本变更或失败时回传可恢复的错误，交付结果未知时先查原请求收据。
- 服务端持续按当前用户检查详情、媒体及写入权限。授权错误复用现有业务口径。观测记录加载失败类型、节点资源失败类型和交付状态，日志避免记录提示词和媒体凭据。

## 关键分支

```text
OPEN(canvasId, mode):
  IF shared: load authorized projection and mount read-only interactions  // B01-01
  ELSE: load owner detail and mount editing session                        // B01-02

REFRESH(canvasId, request, result):
  IF stale request: discard                                               // B01-03
  IF access ended: clear graph and close previews                          // B01-04
  IF transient error: keep graph and show retry                            // B01-05
  ELSE: apply authorized graph and retain current viewport                 // B01-06
  IF authorized and same revision: renew media cookie and keep graph       // B01-10

DELIVER(sourceRevision, requestKey, mode):
  IF existing completed receipt: return original result                   // B01-07
  IF eligibility, staging or final recheck fails: preserve source          // B01-08
  COMMIT recipient canvas, assets and receipt
    IF transfer: retire source and remove its viewer grants                // B01-09
```

## 发布与回滚

预计沿用已有授权、交付和作品数据结构。先在测试环境验证旧授权、旧画布快照及新节点类型。发现只读渲染回归时可回退读页及投影改动，投影与渲染同批回滚。核对既有交付收据和接收方作品仍可查询，再恢复发布。
