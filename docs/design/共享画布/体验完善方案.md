# 共享画布体验完善方案

2026-11-26 · 本地实现与验收记录

## 目标

接收方打开画布时，看到与作者同一已保存版本对应的标准画布。节点、布局、连线和内容保持一致，当前账号的权限决定可用操作和作品归属。适用于普通画布，权限与交付的既有约定见[一期方案](一期方案.md)。

## 改造前的差距

- 截图里的图片长文本卡片和空白导演台来自共享读页自建的 `ReadNode`。标准画布使用 `CanvasNodeView`、`GroupNodeView` 和 `AnimatedSvgEdge`，两者有独立节点注册表。[共享读页](../../../web/src/pages/canvas/shared-reader.tsx) · [标准画布](../../../web/src/components/canvas-editor/canvas-editor.tsx)
- 共享详情另有服务端投影。标准画布保存连线端点与端口并在渲染时恢复样式。改造时核对持久化字段、默认值和素材来源。[共享投影](../../../backend/internal/canvasdoc/share.go)
- 交付服务会创建归接收方所有的新画布，个人列表按归属查询。当前个人列表拉取随初次挂载、查询条件或显式重载触发，接收方已经打开列表时需要补刷新验证。[交付服务](../../../backend/internal/service/canvas_share.go) · [个人画布查询](../../../backend/internal/repository/canvas_project.go) · [列表加载](../../../web/src/hooks/use-canvas-list.ts)

## 三种共享方式

| 方式 | 接收方入口 | 接收方操作 | 交付之后 |
| --- | --- | --- | --- |
| 仅可查看 | 我的作品 → 共享给我 → 画布 | 用标准画布查看原作。支持平移、缩放、展开正文、切换历史结果、播放媒体、查看分镜和导演台。 | 作者继续编辑。接收方可手动刷新，也可开启自动刷新，按 1–60 秒间隔或返回前台时检查已保存版本。默认每 15 秒刷新。作者可撤权，接收方可退出。 |
| 发送副本 | 我的作品 → 个人画布 | 打开标准编辑器，可改名、编辑、保存、上传、生成和使用 Agent。 | 接收方得到独立的新画布和可用素材。从发送时确认的版本继续创作，双方后续改动互相独立。 |
| 转移所有权 | 我的作品 → 个人画布 | 打开标准编辑器，拥有与其他个人画布相同的权限。 | 沿用一期的新 ID 交付。接收方交付完成后，原作退役，旧链接及原查看授权失效。 |

同一接收方先获得只读授权，再收到副本时，两个列表各有一条，分别对应原作和独立副本。副本和转移成功后，发送方提示「对方可在『我的作品 → 个人画布』继续编辑」。接收方进入或切回作品页应看到刚交付的作品，按个人画布既有排序和搜索显示。

## 同版画布的验收口径

- **同一份作品内容**。对比同一已保存版本的标题、节点类型与样式、位置、尺寸、分组及连线，以及正文、角色、分镜、导演台场景、媒体、历史结果和参考素材。导演台至少可查看已保存场景和播放时间轴，分镜表用正式表格阅读。
- **同一套画布操作习惯**。沿用标准画布的背景、缩放控件和节点详情。顶栏展示「仅可查看」、返回共享列表、刷新和退出共享。预览中的播放时间、展开状态和临时选中结果只作用于当前查看界面。首次按已保存视口打开，刷新保留接收方当前视口。作者设备上的临时视口、选区和未保存草稿按一期的已保存版本口径处理。
- **编辑权限按身份生效**。仅可查看时隐藏或禁用编辑工具、生成入口及其快捷键、右键菜单、拖放、粘贴和文件选择入口。服务端继续按当前查看授权与素材引用范围提供读取，写入、生成、上传、导出整图和再共享只由具备相应权限的账号操作。
- **个人画布可继续创作**。副本和转移需保留提示词、创作参数和素材引用。沿用一期的计费归属，接收方用自己的账号权限及额度发起新生成。遇到接收方无权使用的模型时，保留作品内容并允许从可用模型中更换。

## 实施顺序

1. **统一共享读页与标准画布渲染。** 先用含图片长提示词和导演台的固定样本复现截图，再接入标准节点、分组、连线、视口和媒体预览。逐项补齐分镜、导演台与历史结果的只读交互，并同步审查共享投影。
2. **贯通接收方的个人画布。** 保留现有交付路径，补作品列表回前台刷新、成功反馈及接收方编辑、保存、生成验证。覆盖已查看原作后收到副本、转移后旧授权失效两种组合场景。
3. **完成双账号验收后一起发布。** 同一份混合画布按三种方式交付，核对列表归属、渲染、权限、撤权、素材完整性和转移失败。已有授权沿用原读页地址，已有副本和转移作品继续按个人画布打开。

## 验收标准

| 编号 | Given | When | Then | 验证层级 |
| --- | --- | --- | --- | --- |
| AC01 | A 保存含图片、音视频、分组、连线、角色、分镜和导演台的画布 | A 打开原画布，B 打开共享读页 | 同一视口下两端作品区按节点逐项一致。B 能打开分镜、播放导演台及媒体、切换历史结果 | 前端组件测试、双账号人工对照 |
| AC02 | B 仅有查看权限 | B 使用节点详情、键盘、菜单或拖放等入口 | 查看动作可用，节点和连线不变，请求记录无保存、生成、上传或 Agent 运行，服务端拒绝无权写入 | 前端请求断言、后端 HTTP 集成 |
| AC03 | B 正在查看原作 | A 保存新版本后 B 手动或自动刷新，再由 A 撤权或 B 退出 | 版本不变时保留当前画布。版本变更时更新内容并保留视口。权限结束后服务端拒绝详情和媒体，页面复核后清空画布及预览并提示 | 前端组件、后端 HTTP 集成 |
| AC04 | B 的个人画布列表已打开，且 B 可以查看 A 的原作 | A 发送副本，B 回到作品页、打开副本、编辑并提交一次生成 | 副本只新增于个人画布，原只读授权仍在共享列表。副本保存和生成属于 B，A 后续改动不影响副本 | 列表组件、交付集成、双账号验证 |
| AC05 | A 拥有原作，C 有查看权 | A 将所有权转给 B，B 打开新画布 | B 在个人画布可编辑和生成，A 和 C 的旧画布及旧媒体链接失效 | 交付集成、双账号验证 |
| AC06 | 源版本冲突、必需素材复制失败、转移竞争或响应超时 | A 提交、重试或核实结果 | 失败时原作和授权可用，目标无半成品。同一次成功交付只出现一张目标画布 | 后端仓储集成与故障注入 |
| AC07 | 焦点刷新遇到网络中断、请求乱序或未授权媒体 | B 继续预览或重试 | 网络错误给出可重试状态，确认失权时清空内容，旧响应不能恢复已撤权内容；缺失媒体有节点级提示 | 前端组件、后端 HTTP 集成 |

测试目标和权限分支见[体验完善技术设计](体验完善技术设计.md)。

## 本地验收结果

- 两个临时账号打开同一已保存画布。图片、视频、分镜、导演台这四个节点的位置和尺寸一致，连线数量一致，共享页没有画布编辑菜单。分镜中的真实视频可播放并跳到 1.25 秒。导演台加载了 WebGL 场景，时间轴从 0 播放至 5 秒并可切换已保存机位。
- 发送副本后原作仍在共享列表，副本可从个人画布打开并保存。转移后原作及旧媒体返回 `404`，已打开的共享页刷新后清空内容。个人列表在焦点刷新后出现转移作品，接收方可打开标准编辑器并保存。相同请求键重放只交付一次。
- 隔离 PostgreSQL 验证了只读账号生成被拒绝，副本和转移的接收方可以提交生成任务，积分冻结在接收方账户。预览环境无可用模型，真实供应商出片与最终扣费仍需在有测试模型的环境验收。
- 2026-11-27 的工作台改造以组件测试验证了只读工作台外壳、浏览控件与按版本刷新。隔离 PostgreSQL 的双账号 HTTP 测试验证了作者保存后查看者能读取新版、只读账号无法保存，以及撤权后版本探测与媒体请求都失效。

## 产品决定

只读页按已保存版本更新。点击「刷新」立即检查一次。下拉菜单可选「不刷新」或「自动刷新」。启用自动刷新时，用滑杆设置 1–60 秒的间隔，默认 15 秒，窗口回焦也会触发检查。选择「不刷新」后，首次加载完成后只手动检查。浏览器记住刷新模式和上次设置的间隔。转移使用新 ID 并使旧链接失效。作者私有的 Agent 会话和账单按账号隔离。
