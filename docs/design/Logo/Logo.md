# 品牌 Logo 与字标

## 问题和目标

现在的 Logo「镜间光」（`web/src/components/brand/logo.tsx`）是两个直角括号加一道光束，名字「连镜」直接用系统字体，整体偏方正、偏工具感。目标是让 Logo 和字标更圆润、更飘逸、更有艺术感，同时保留琥珀光束（`--beam` / `--beam-bright`）和「取景、镜头」这层意思。

## Logo：A「流光」（已定）

- 两道毛笔弧作取景框，中间一缕 S 形琥珀光穿过，光的两端渐隐。
- 笔触由 `logo-gen.py` 生成：输入骨架曲线和笔宽曲线，输出填充轮廓。要调形状就改骨架点，不手改输出的 path。
- 墨色用 `currentColor`；光用 `--beam`，登录页舞台用 `--beam-bright`。

> 变更：原为直角括号「镜间光」。

## 字标「连镜」

定稿：继续用正常字体（系统字体），不做定制字标。手绘笔触、开源书法字体、两字交叠三个方向都试过，均未采用；原型里保留了书法字体的对比，仅作记录。

## 动效

| 触发     | 属性                  | 时长 / 曲线       | 说明         |
| -------- | --------------------- | ----------------- | ------------ |

| 减少动态 | 不做动画              | —                 |              |

### 加载动画「开镜 · 对焦 · 光铺开」

替换现有加载层（`FocusLoader` + `index.css` 的 canvas-focus-*）里的 Logo 动画。Logo 拆成左弧、右弧、光束、光晕四个叠放的 SVG，只动 transform / opacity，全部写成 CSS 关键帧，画布挂载占住主线程时也不掉帧。

| 阶段         | 元素     | 属性                                              | 时长 / 曲线                                  |
| ------------ | -------- | ------------------------------------------------- | -------------------------------------------- |
| 进场「开镜」 | 左 / 右弧 | translateX ±14% → 0，opacity 0 → 1                 | 0.9s `cubic-bezier(0.2,0,0,1)`               |
|              | 光束     | scale(0.6, 0.05) → scale(1, 1.1) → 1，从中心点亮   | 0.75s，延迟 0.15s，同一曲线                   |
|              | 字标与说明 | 沿用聚焦显影：blur 12px、scale 1.08 → 清晰        | 0.9s，延迟 0.12s                              |
| 加载中「对焦」 | 左 / 右弧 | 向内收 4% 再放开                                   | 1.6s ease-in-out 循环（生成中的状态指示，允许循环） |
|              | 光束 / 光晕 | scaleY 1 → 1.06；光晕 opacity 0 → 0.7            | 同上                                          |
| 退场「光铺开」 | 左 / 右弧 | 向外 24%，淡出                                     | 0.32s `cubic-bezier(0.4,0,1,1)`              |
|              | 光束     | scale(4, 1.4)，淡出                                 | 0.36s，同一曲线                               |
|              | 整层     | opacity → 0                                        | 0.38s，延迟 0.1s（与现有一致）               |
| 减少动态     | 全部     | 只做淡入淡出，不循环                               | —                                            |

最短停留仍是 `MIN_SHOW_MS = 900`：进场放完才允许退场。
