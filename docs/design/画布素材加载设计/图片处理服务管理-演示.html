给画布素材接上图片处理服务

缩略图和视频封面不再由后端生成，而是交给云厂商的图片 / 视频处理服务。后台新增一个独立模块「图片处理服务管理」，管理“哪套存储、用哪家服务处理”。这份文档演示三家厂商（Cloudflare R2、腾讯云、阿里云）怎么对接，以及腾讯云这类“必须配套自家存储”的服务怎么在后台里表达。

一条请求怎么走

前端和 payload 都不变，仍然引用稳定地址。后端只多做一件事：按素材所在的存储，找到绑定的已发布处理服务，把请求 302 到厂商的处理 URL。

浏览器<img src="/files/<key>?v=thumb">
视频封面用 ?v=poster
后端 /files查素材 → 找到它所在的存储 → 找到该存储绑定的已发布处理服务
302 跳转目标是厂商的处理 URL（私有桶会带签名）
厂商处理存储侧 / 边缘 / 自部署；结果由厂商缓存
小图返回约几十 KB，而不是几 MB 原图
设计：后端不读原图、不占 CPU、不装 ffmpeg。处理服务是“存储的附属能力”，所以解析路径是 素材 → 存储 → 处理服务，而不是全局只有一个处理服务。
没有处理服务时（回退，永远可用）：图片 302 到原图（和今天一样）；视频封面返回 404，前端显示占位图标，点击仍可播放。所以未配置、已停用、处理失败，都不会让画布坏掉。

三种对接形态

不同厂商的处理服务“长在”不同的地方，这决定了后台里怎么绑定。AWS 动态图片转换需要客户自部署，且官方文档未查到视频首帧支持，本期不做。

客户要对接腾讯云时，会发生什么

腾讯云的图片处理绑定对象存储，必须使用自家的 COS。而素材记录了自己所在的存储，所以这件事分四步，并且有一个需要提前说清的边界。

  1. 在存储配置新建一套腾讯云 COS 存储桶名要带 APPID 后缀，例如 canvas-1250000000
  2. 在腾讯云控制台为该桶开通数据万象，要封面再开通媒体处理视频截帧是单独开通、单独计费的
  3. 在图片处理服务管理新建「腾讯云数据万象」，只能绑定这套 COS 存储绑到其他存储时被禁用，并写明原因
  4. 校验、试跑通过后发布；把 COS 设为默认存储，之后的新素材才写进去老素材在原存储里，不受影响
边界：处理服务只覆盖它绑定的存储。
假设素材现在在 R2，客户新建 COS 并设为默认：
  • 新上传、新生成的素材写进 COS → 走数据万象，有缩略图
  • R2 里的老素材 → 仍由 R2 绑定的处理服务（或回退原图）
  • 要让老素材也走腾讯云，需要先把它们迁到 COS；存储迁移在存储配置设计里放在二期

后台不做覆盖统计，也不做存储迁移（已确认）；这个边界要在交付给客户时说明。

处理服务和存储的关系

一个存储同一时间最多绑定一个“已发布”的处理服务；一个处理服务只绑定一个存储。每个厂商只能绑定它允许的存储类型。

处理服务允许绑定的存储为什么
腾讯云数据万象tencent_cos数据万象绑定 COS 存储桶，只能处理存在自家桶里的素材
阿里云 OSS 图片处理aliyun_ossx-oss-process 是 OSS 域名的能力
Cloudflarer2，且已设置公开域名处理发生在 Cloudflare 域名上，源是 R2 的公开地址

后台接口

方法与路径说明
GET /admin/image-processors/presets下发厂商预设：允许绑定的存储、可配置字段、能力（图片 / 视频封面）、限制提示
GET|POST /admin/image-processors列表、新建草稿；绑定关系不匹配返回业务错误
PUT /admin/image-processors/:id保存草稿；带版本号做乐观锁
POST /…/:id/validate校验：绑定关系、域名可达、厂商前置条件
POST /…/:id/trial试跑：用一个真实图片素材和一个视频素材各走一遍，返回体积和耗时
POST /…/:id/publish发布（校验和试跑通过才允许）；同存储已有已发布版本时替换它
POST /…/:id/rollback回滚到上一个已发布版本
POST /…/:id/disable停用：该存储回退原图 / 占位
DELETE /…/:id只允许删除草稿或已停用的

已确认的决定

  1. 引入 COS Go SDK 与 OSS Go SDK：都引入。COS Go SDK v0.7.75（MIT）、OSS Go SDK v2 v1.6.0（Apache-2.0），用于私有读桶的带处理参数签名，以及阿里云视频首帧。API 与构建细节实现时核对。
  2. 一个存储同时只有一个已发布的处理服务；换厂商时先停用，或发布新的自动替换旧的（可回滚）。
  3. 老素材在别的存储里：不用管。后台不展示覆盖统计，也不做存储迁移。
  4. AWS 动态图片转换不做：本期只做阿里云、腾讯云、Cloudflare R2。
  5. Cloudflare 只支持 R2，不处理其他来源的素材。
  6. 主文档已回写：第 6.2 节的存储接口方案已改为这里的处理服务实体，并新增 6.6 节描述后台模块。
