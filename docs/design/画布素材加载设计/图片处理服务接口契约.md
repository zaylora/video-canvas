# 图片处理服务接口契约

> 前后端并行开发用的约定，来源是 [画布素材加载设计.md](./画布素材加载设计.md) 第 6.2、6.6 节与 [图片处理服务管理-演示.html](./图片处理服务管理-演示.html)。后端实现如与本文有出入，以改本文为准，并同步前端 `api/admin-image-processor/endpoints.ts`。
> 约定沿用存储配置模块：前缀 `/api/v1`，响应统一信封（`response.OK`），JSON 字段 snake_case；GET 可由 admin 访问，写操作仅 super_admin。

## 1. 素材变体：`GET /files/<key>?v=thumb|poster`

前端不调接口，只改 URL：节点 `src` 形如 `/files/<key>`（可能是相对路径，也可能带域名），在后面加 `?v=thumb`（图片缩略图）或 `?v=poster`（视频封面）。

| 情况                                                                      | 响应                         |
| ------------------------------------------------------------------------- | ---------------------------- |
| 素材所在存储有已发布的处理服务，且支持该变体                              | `302` 到厂商处理 URL         |
| `thumb` 但没有处理服务 / 不支持                                           | `302` 到原图（等同没带 `v`） |
| `poster` 但没有处理服务 / 不支持                                          | `404`                        |
| 素材种类与变体不匹配（图片请求 `poster`、视频请求 `thumb`、音频任何变体） | `404`                        |
| `v` 取值不是 `thumb` / `poster`                                           | `404`                        |

所以前端必须把 `<img>` 的 `error` 当作可回退情况：缩略图加载失败 → 改用原图；封面失败 → 显示占位。

## 2. 后台接口：`/admin/image-processors`

### 2.1 数据结构

```ts
type ProcessorVendor = "cloudflare" | "tencent_ci" | "aliyun_oss_img";
type ProcessorStatus = "draft" | "published" | "disabled";

interface ProcessorConfig {
  domain: string; // 访问域名，只写 host，不带协议（如 assets.example.com）
  width: number; // 缩略图 / 封面长边，16–2000，默认 512
  format: string; // 输出格式，见预设 formats
  time_sec: number; // 视频封面取帧时间（秒），≥0，默认 0；不支持封面的厂商忽略
  quality?: number; // 仅 cloudflare：1–100，默认 75
  on_error_redirect?: boolean; // 仅 cloudflare：处理失败回退原图，默认 true
  media_enabled?: boolean; // 仅 tencent_ci：已开通数据万象“媒体处理”，未开通时没有视频封面
}

interface CheckItem {
  key: string; // 稳定标识，如 binding / domain / sign / trial_image / trial_video
  label: string; // 中文名
  status: "ok" | "warn" | "fail";
  message: string;
}

interface ProcessorCheck {
  ok: boolean; // 没有 fail 即为 true（warn 不挡发布）
  version: number; // 这次校验针对的处理服务 version
  checked_at: string; // ISO 时间
  checks: CheckItem[];
  trial: {
    // 试跑：用该存储里的真实素材各取一次，没有素材时对应项为 null
    image: { bytes: number; ms: number; source_bytes: number } | null;
    video: { bytes: number; ms: number } | null;
  };
}

interface ProcessorView {
  id: number;
  name: string;
  vendor: ProcessorVendor;
  storage_id: number;
  storage_name: string;
  storage_provider: string; // local / aliyun_oss / tencent_cos / s3 / r2
  status: ProcessorStatus;
  config: ProcessorConfig; // 工作配置（草稿）；已发布且没改过时与 published_config 相同
  published_config: ProcessorConfig | null; // 线上正在用的配置；从未发布为 null
  has_draft: boolean; // 已发布，且 config 与 published_config 不同
  published_version: number; // 线上版本号，从未发布为 0
  previous_version: number | null; // 可回滚到的上一个版本号，没有为 null
  version: number; // 乐观锁版本，每次保存草稿 +1
  check: ProcessorCheck | null; // 最近一次校验与试跑；保存草稿后其 version 落后于 version，前端据此判断“需要重新校验”
  updated_at: string;
  created_at: string;
}

interface ProcessorPreset {
  vendor: ProcessorVendor;
  name: string; // 中文厂商名
  storage_provider: "r2" | "tencent_cos" | "aliyun_oss"; // 只能绑定这种存储
  requires_public_base: boolean; // cloudflare 为 true：存储必须已设置公开域名
  supports_poster: boolean; // 是否支持视频封面
  formats: string[]; // 可选输出格式，第一个是默认
  default_config: ProcessorConfig;
}
```

### 2.2 接口

| 方法与路径                                  | 权限  | 说明                                                                                                                                                |
| ------------------------------------------- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /admin/image-processors/presets`       | admin | `ProcessorPreset[]`，顺序即展示顺序                                                                                                                 |
| `GET /admin/image-processors`               | admin | `ProcessorView[]`（可能为 `null`，前端补成空数组）                                                                                                  |
| `GET /admin/image-processors/:id`           | admin | `ProcessorView`                                                                                                                                     |
| `POST /admin/image-processors`              | super | body `{ name, vendor, storage_id, config }` → 新建草稿，返回 `ProcessorView`                                                                        |
| `PUT /admin/image-processors/:id`           | super | body `{ version, name, config }` → 保存草稿（整份提交，不改 vendor / storage_id），`version` 乐观锁，返回 `ProcessorView`。已发布的线上配置不受影响 |
| `POST /admin/image-processors/:id/check`    | super | 校验 + 试跑，结果写入 `check`，返回 `ProcessorView`（含最新 `check`）。校验未通过也返回 200，看 `check.ok`                                          |
| `POST /admin/image-processors/:id/publish`  | super | body `{ version }` → 发布当前草稿。要求 `check.ok` 且 `check.version === version`；同存储已有已发布的处理服务时，旧的自动变为 `disabled`            |
| `POST /admin/image-processors/:id/rollback` | super | 回滚到上一个已发布版本，返回 `ProcessorView`                                                                                                        |
| `POST /admin/image-processors/:id/disable`  | super | 停用已发布的处理服务，该存储回退原图 / 占位                                                                                                         |
| `DELETE /admin/image-processors/:id`        | super | 只允许删除 `draft` / `disabled` 的                                                                                                                  |

响应体：`presets` 返回 `ProcessorPreset[]`；`DELETE` 返回空；其余接口（含 `check` / `publish` / `rollback` / `disable`）一律返回最新的 `ProcessorView`。后端已按本文实现（`backend/internal/handler/admin_image_processor.go`），前端类型与之逐字段核对过。

### 2.3 业务错误码（52xxx）

| 码    | HTTP | 含义                                                                                      |
| ----- | ---- | ----------------------------------------------------------------------------------------- |
| 52001 | 404  | 处理服务不存在                                                                            |
| 52002 | 409  | 名称已存在                                                                                |
| 52003 | 400  | 配置不合法（具体原因在 msg）                                                              |
| 52004 | 409  | 版本冲突：已被他人修改，请刷新后重试                                                      |
| 52005 | 400  | 厂商与存储不匹配（腾讯云只能绑 COS、阿里云只能绑 OSS、Cloudflare 只能绑 R2 且需公开域名） |
| 52006 | 409  | 该存储已被另一个已发布的处理服务绑定（仅在发布时给出提示用；发布本身会替换，见上）        |
| 52007 | 409  | 当前草稿还没有通过校验与试跑，不能发布                                                    |
| 52008 | 409  | 已发布的处理服务不能删除，请先停用                                                        |
| 52009 | 409  | 没有可回滚的版本                                                                          |
| 52010 | 409  | 处理服务不是已发布状态，无法停用 / 回滚                                                   |

### 2.4 绑定与校验规则

- 一个处理服务只绑定一个存储，创建后不可改；一个存储同时最多一个 `published`。
- `cloudflare` ↔ 存储 provider `r2`，且存储 `public_base_url` 非空，`config.domain` 必须等于该 URL 的 host。
- `tencent_ci` ↔ `tencent_cos`；`aliyun_oss_img` ↔ `aliyun_oss`。
- 校验项（`check.checks`）：`binding`（绑定关系）、`domain`（域名可访问）、`public_domain`（仅 cloudflare：与存储公开域名一致）、`media`（仅 tencent_ci：媒体处理开关，未开通为 warn）、`custom_domain`（仅 aliyun：默认 OSS 域名为 warn）、`sign`（私有读签名可用）、`trial_image`、`trial_video`（厂商不支持封面或没有视频素材为 warn）。
