让 AI 写插件少走几轮

插件要来回调好几次，一大原因是契约里有不少 AI 从 API 文档里推不出来的“平台专属规则”。这次删掉结果下载域名白名单，删掉“允许访问内网”开关，让结果支持简写，提示词变短，版本号自动递增，出错时一键把修复信息复制给 AI。 安全边界：渠道 Key 只会发往渠道自己的 base_url，任何请求都不能访问内网。

一个生成任务的请求怎么走（改后）

回答：去掉白名单以后，宿主靠什么守住 Key 和内网。

插件返回请求描述path 或绝对地址 url
宿主判断“是不是渠道地址”协议、域名、端口和 base_url 完全一致，才注入 Key
拨号时拦截内网所有渠道一样；按 DNS 解析结果判断，防止域名临时指向内网
插件返回结果可以简写，宿主补全成完整格式
下载结果任何公网域名都行；重定向 ≤3 次，有大小上限和超时
设计：白名单原来同时管着“结果从哪下载”和“请求能去哪”。拆开以后，Key 的安全靠“同源才注入”，内网的安全靠拨号拦截，两件事都不再需要插件声明域名。
兜底：旧插件里写的 allowedHosts 会被直接忽略，不报错，不用重新上传。绝对地址请求如果上游需要 Key，就会收到 401/403，按“终止”失败；试跑追踪里会写明“目标不是渠道地址，未注入 Key”，方便定位。

接入 YSWG 这类平台时，会发生什么

回答：结果放在第三方 OSS 上的平台，从写插件到出图的路径，以及需要提前说清的边界。

  1. 复制提示词，粘贴平台文档发给 AIAI 先检查信息是否齐全，缺什么就问什么（保留现状）
  2. AI 输出插件，里面不再有域名清单结果可以直接写 outputs: [body.data.url]
  3. 上传预检如果失败，点“复制修复信息”发回给 AI；改完直接重新上传，版本号自动递增
  4. 试跑结果在 cyapi-ai.oss-us-west-1.aliyuncs.com 上也能直接下载入库
  5. 如果失败，再复制一次修复信息里面带失败步骤的输入和输出，已脱敏
边界：Key 不会跟着绝对地址出门。
  • 平台如果要求“先 PUT 到 OSS 预签名地址”，可以做，因为这类地址本身不需要我们的 Key。
  • 平台如果把接口拆到两个域名（如 api.x.com 和 upload.x.com），而且都要 Key，第二个域名拿不到 Key。这种情况需要渠道拆开，或者插件改用 auth: custom（插件自己持有 Key，需要超级管理员开“允许插件读取 Key”）。
  • 升级前开过“允许访问内网”的渠道，升级后会失败，日志里会有 WARN。

上线前要在 CHANGELOG 里写明：白名单字段 allowedHosts 已删除、“允许访问内网”开关已删除。

规则关系

回答：哪类出站请求允许去哪，带不带 Key。

出站请求允许的目标带 Key为什么
请求描述 path只有 base_url是不变
请求描述 url，同源base_url 的协议、域名、端口是等价于 path
请求描述 url，非同源任意公网 http/https否用于预签名上传等场景；Key 不离开渠道
下载结果任意公网 http/https否（现状也不带）结果域名不可预知
Agent 大模型网关只有 base_url是不变，只去掉内网放行
任何请求访问内网一律拦截—“允许访问内网”删除

数据模型

ai_channels 表

version可以不写；登记时由 service 决定最终值，并回写到 meta_json；代码原文和 sha256 不变

// 宿主：结果规范化，在原校验之前（提案）
func normalize(r *result, kind string) {
  for i, o := range r.Outputs {
    if s, ok := o.(string); ok {
      if kind == "text" { r.Outputs[i] = {type:"text", text:s} }
      else              { r.Outputs[i] = {type:"url",  url:s} }
    } else if o.type == "" {
      if o.url  != "" { o.type = "url"  }
      if o.text != "" { o.type = "text" }
    }
  }
  if s, ok := r.Error.(string); ok { r.Error = {class:"terminal", message:s} }
  if r.Error != nil && r.Error.class == "" { r.Error.class = "terminal" }
  // status 不放宽；class 写了但不合法 → 仍然算插件故障
}
// 服务：上传时决定版本号（提案，仅上传的插件）
func decideVersion(meta, existing, sha) (string, error) {
  if len(existing) == 0 {
    if validSemver(meta.Version) { return meta.Version }
    return "1.0.0"
  }
  if v := existing.findBySHA(sha); v != nil {
    return reject("代码与 v" + v + " 完全相同，没有产生新版本")
  }
  max := existing.maxSemver()
  if validSemver(meta.Version) && !existing.has(meta.Version) &&
     semverGT(meta.Version, max) {
    return meta.Version
  }
  return fmt.Sprintf("%d.%d.%d", max.Major, max.Minor, max.Patch+1)
}
