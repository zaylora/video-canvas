# 渠道与插件弹窗对齐模型弹窗

> 2026-10-09 · 原型：[渠道与插件弹窗对齐模型原型.html](渠道与插件弹窗对齐模型原型.html)
> 关联：[渠道与插件表格化.md](渠道与插件表格化.md) §3.3 渠道弹窗、§3.5 插件弹窗（本文件修订这两节的版式，字段内容不变）

## 1. 问题和目标

模型编辑弹窗已经有一套成熟的版式：头像头部、带图标的下划线页签、`FormSection` 平铺分块、统一底栏。渠道、插件弹窗还是另一套：

- 头部没有头像，信息密度和模型弹窗不一致。
- 页签是药丸式（`ui/tabs`），和模型的下划线页签不统一。
- 正文是一块块带边框的 `Zone` 卡片（渠道）和带格线的信息表（插件），框套框，视觉很碎。
- 渠道底栏内边距、文案和模型底栏不一致。

目标：渠道、插件弹窗的**壳**（头部 / 页签 / 分块 / 底栏）与模型弹窗一致；字段、校验、保存流程不变。

已确认：**不加右侧栏**，只借结构（渠道、插件没有“创作端预览”可放，加了只会重复左边的信息）。

## 3. 控件说明

| 项 | 说明 |
| --- | --- |
| 弹窗尺寸 | 渠道 `sm:max-w-3xl`（原 4xl），`h-[min(88svh,800px)]`；插件 `sm:max-w-3xl`，`h-[min(88svh,760px)]`；都是 `p-0 gap-0 overflow-hidden`，窄屏 `max-w-[calc(100%-1.5rem)]` |
| 头部 | `flex items-start gap-4 border-b px-6 py-4`：`InitialAvatar size-10 text-base`（seed 用 key）+ 标题行 + 副标题 + 关闭 `Button ghost icon-sm`。没有“⋯”菜单（已确认头部不放操作） |
| 渠道标题行 | `DialogTitle text-lg font-semibold`（“渠道”前缀不加，直接名称；新建为“新建渠道”）+ 健康状态 `Tag`（可用 = `success` + `StatusDot`，未设 Key / 已停用 = `warning`，不可用 = `danger`，同 `channelHealth()`）；表单有未保存修改时追加 `Tag tone=warning`“有未保存修改”（同模型弹窗） |
| 渠道副标题 | `text-muted-foreground mt-0.5 truncate text-sm`：`<mono>key</mono> · 插件名 vX` |
| 插件标题行 | 名称 + 来源 `Tag`（内置 / 已上传，中性） |
| 插件副标题 | `<mono>key</mono> · vX.Y.Z` |
| 下划线页签 | 新增 `admin-ui/underline-tabs.tsx`（`UnderlineTabs / UnderlineTabsList / UnderlineTabsTrigger / UnderlineTabsContent`，基于 Base UI Tabs，带 `data-slot`）：`border-b px-4`，每项 `-mb-px inline-flex items-center gap-2 border-b-2 px-3 py-3 text-sm font-medium`，选中 `border-foreground text-foreground`，未选 `text-muted-foreground border-transparent hover:text-foreground`；图标 `size-4`；计数 `tabular-nums text-xs text-muted-foreground`。样式与模型弹窗页签逐项一致，模型弹窗改用同一个组件，不再手写 |
| 页签图标 | 渠道：配置 `SlidersHorizontal`、模型 `Boxes`；插件：概览 `Info`、版本历史 `History` |
| 分块 | 全部用 `admin-ui/form-section`（`FormSection / Header / Title / Description`），去掉 `Zone` 的 `rounded-lg border p-3.5`。标题 `text-sm font-semibold` + 一句 `text-xs` 说明；块间距 `mb-7` |
| 渠道分块 | **平台**（卡片组，不变）· **连接**（接口地址、API Key，两列 `grid sm:grid-cols-2 gap-x-6 gap-y-4`）· **名称**（渠道名称、渠道标识，两列）· **高级设置**（`Collapsible`，标题行可点，右侧 chevron；有新版本时默认展开）。去掉“1 · 2 · 3 ·”编号，顺序由上到下已经表达 |
| 高级设置内 | 插件版本、限流、启用各为一个 `FormSection`（小标题 + 说明）；**安全开关**保留琥珀描边：`FormSection` 内的两行开关放进 `rounded-lg border border-amber-500/60 p-3.5 divide-y`，因为它是唯一需要警示的块 |
| 检查结果条 | 取代原“连通性检查”Zone：页签下方一条 `border-b px-6 py-2.5 text-sm`（同模型弹窗的提示条位置）。左 `CheckResult`，检查通过时右侧 `[从这个渠道导入模型] [新建模型]`（沿用原条件：插件不支持导入则只有新建）；没检查过不出现；未设 Key 的提示条 `bg-amber-500/10` 同位置显示一行字 |
| 模型页签 | 内容不变，容器 `px-6 py-5` |
| 底栏 | `flex flex-wrap items-center gap-3 border-t px-6 py-3.5`：左 `text-muted-foreground text-xs leading-tight`（新建：“选平台 → 填地址和 Key → 起个名字，点「保存并检查」就能用”；编辑：“保存后自动检查连通性”；只读：“只读 · 需要运维权限”）；右 `ml-auto` 取消（outline）+ 保存并检查（主按钮）。**模型页签下没有底栏**（只有配置页签有） |
| 插件信息 | 原带格线的边框表格改为 `DescriptionList`（`grid-cols-2 gap-x-6 gap-y-4`，字段名在上、值在下），没有外框；允许下载域名 `Tag mono` 换行；“支持”用 `text-foreground` + ✓ |
| 生成方式卡片 | 不变（中性卡片，支持 / 不支持两态）；外层从 Zone 换成 `FormSection` |

## 4. 动效

无新增。弹窗开合沿用 `ui/dialog` 默认（200ms 进 / 150ms 出，中心缩放）；页签切换内容直接切换，选中下划线直接跳位（与模型弹窗一致）；高级设置展开沿用 `ui/collapsible` 现有行为；按钮用现有 `Button` 的按下反馈。`prefers-reduced-motion` 下没有额外动画需要降级。

## 5. 状态表

| 状态 | 渠道弹窗 | 插件弹窗 |
| --- | --- | --- |
| 加载 | 插件清单未就绪：平台块显示 `Skeleton`（现有逻辑） | 无（数据来自列表） |
| 新建 | 无页签，头部下方直接是正文；底栏左侧写三步引导 | — |
| 编辑 | 配置 / 模型 两页签 | 概览 / 版本历史 两页签 |
| 检查中 | 底栏按钮 `Loader2` 旋转，禁用 | — |
| 检查结果 | 页签下的结果条 | — |
| 有未保存修改 | 标题旁 `Tag warning`；关闭仍先确认“放弃修改？” | — |
| 只读（无写权限） | 表单 `disabled`，底栏左侧“只读 · 需要运维权限”，只有“关闭” | 无写操作 |
| 窄屏 < 768px | 两列字段变一列；页签、头部不变；`max-w-[calc(100%-1.5rem)]` | 信息列表 1 列 |
| 深浅主题 | 全部走 token 与 `Tag` 语气色 | 同左 |

| `web/src/pages/admin/ai/plugins/plugin-dialog.tsx` | 头部头像化；`Tabs` 换 `UnderlineTabs`；`FormSection` + `DescriptionList` 取代信息格线表；简介移到概览顶部 |

变更（相对 [渠道与插件表格化.md](渠道与插件表格化.md)）：

- §3.3 渠道弹窗：原为药丸页签 + 边框 Zone 卡片 + 4xl 宽；现为下划线页签 + 平铺分块 + 3xl 宽；“连通性检查”Zone 改为页签下的结果条。
- §3.5 插件弹窗：原为药丸页签 + 带格线信息表；现为下划线页签 + `DescriptionList`。
- 头部操作（启用、删除、检查、导入、更新 Key）已在上一轮按用户要求移除，仍以表格行里的操作为准。

## 7. 依赖

无（Base UI Tabs、`form-section`、`description-list`、`collapsible` 都已有）。
