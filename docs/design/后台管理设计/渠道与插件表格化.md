# 渠道与插件表格化

> 2026-10-09 · 原型：[渠道与插件表格化原型.html](渠道与插件表格化原型.html)
> 关联：[后台交互优化设计.md](后台交互优化设计.md)（§5.3 渠道一屏建完的表单内容不变，只是容器从抽屉换成弹窗页签）

## 1. 问题和目标

- 渠道页、插件页是“左列表 + 右详情”，模型页已经是“表格 + 弹窗”，三页交互不一致。
- 详情区堆了很多提示条（插件已停用、未设 Key、有新版本、只读说明、各种副标题），重点被淹没。
- 能力用蓝 / 紫 / 红 / 橙四色区分，和中性灰的主题不搭，看起来乱。

目标：

1. 渠道、插件都改成 **表格 + 详情弹窗**，和模型页一致；常用操作直接在表格行里完成。
2. 去掉不改变决策的提示：状态由状态列 / 开关表达，问题写在出问题的那个字段旁边，不再用横幅。
3. 颜色用 Tag 同一档语气色（浅底 `500/10` + 浅色主题 700 / 深色主题 400 的文字或图标），不再单独调淡；来源、版本用中性色；只有图标、操作文字和状态带颜色，不出现大块彩色底。

## 3. 控件说明

### 3.1 通用表格（两页共用的写法，照模型表 `ModelRows`）

| 项 | 说明 |
| --- | --- |
| 容器 | `bg-card rounded-xl border`，顶部工具条 `p-4 flex-wrap gap-2`：搜索框 `sm:w-64 h-8` + 筛选项（见 §3.2 / §3.4）+ 有筛选生效时出现“重置”（行内操作样式）+ 右侧计数 `筛选数 / 总数`（`tabular-nums`） |
| 筛选控件 | 能力用 `Segmented`（全部 / 文本 / 图片 / 视频 / 音频）；其余用 `NativeSelect h-8 w-auto text-xs`（同模型表），选了非“全部”时描边加深（`border-foreground/35`）表示生效。任何筛选或搜索变化都回到第 1 页。筛选只在前端做，不进 URL |
| 表头 | `text-xs text-muted-foreground`，`px-3` |
| 行 | `py-3`，整行 `cursor-pointer`，点击打开弹窗；hover `bg-muted/50`（`ui/table` 默认） |
| 首列 | 名称 `font-medium` + 下一行 key `font-mono text-xs text-muted-foreground` |
| 启用列 | `Switch`，点击不冒泡到行；无写权限时 `disabled`，`title="需要运维权限"` |
| 操作列 | 右对齐，`whitespace-nowrap`，点击不冒泡。**所有操作常驻露出，不用 ⋯ 菜单**：每个是“图标 + 文字”的轻量按钮（新增 `admin-ui/row-action.tsx`：`h-7 px-2 rounded-md text-xs`，文字和图标都用语气色 700/400，hover 底色为语气色 10%，按下 `TAP`，禁用 `opacity-40` + `title` 说明原因） |
| 加载 | 4 行 `Skeleton h-9` |
| 失败 | 整行 `text-destructive`“加载失败 重试” |
| 空 | 整行居中 `text-muted-foreground`，带一个主操作文字链（新建渠道 / 上传插件；无权限时只有文字） |
| 无匹配 | “没有匹配的渠道 / 插件” |
| 分页 | 表格下方**始终显示** `DataTablePagination`：左侧每页条数（10 / 20 / 50，默认 10）+“共 N 条”，右侧“第 x / y 页”+ 上一页 / 页码 / 下一页。前端分页，页码不进 URL；数据刷新后当前页超出总页数时落到最后一页 |
| 窄屏 < 768px | 表格外层 `overflow-x-auto`，首列和操作列不隐藏，能力 / 负载列 `max-md:hidden`；工具条换行，搜索框占满一行；分页 < 640px 隐藏页码数字只留上一页 / 下一页 |

### 3.2 渠道表

| 列 | 内容 |
| --- | --- |
| 渠道 | 名称 / key |
| 插件 | `插件名 vX.Y.Z`；有新版本时第二行 `text-xs text-muted-foreground`“可升级到 vX” |
| 能力 | `KindIcons`（中性色，见 §3.6） |
| 模型 | 使用它的模型数，`tabular-nums`；模型列表没加载完显示 `—` |
| 负载 | `生成中 · 排队`；配了上限写 `1/4`；满了数字变 `text-status-warning`；排队 > 0 同色 |
| 状态 | `StatusLabel`（可用 / 未设 Key / 不可用 / 已停用）；只有“不可用”时第二行 `text-xs text-muted-foreground` 写原因（`channelHealth().reason`），其余看标签就够了；不在表格里显示检查结果 |
| 启用 | `Switch`：停用走现有确认框（写明波及几个上架模型），启用直接生效 |
| 操作 | `导入`(success；插件不支持时禁用) · `设置 Key / 更新 Key`(warning) · `删除`(danger，打开现有删除对话框)。**表格里没有“检查”**：连通性检查只在渠道弹窗里（头部按钮、概览顶部的结果、配置页的保存并检查） |

- 弹窗头部的 `检查` 点击后立即变成 `Loader2` 旋转 +“检查中”，禁用；结果显示在概览页签顶部。不弹 toast（失败的全局 toast 拦截器已经弹）。
- admin（只读）：只剩“导入”。

筛选：能力（插件声明了该能力）· 插件（全部插件 / 各插件名）· 状态（全部状态 / 可用 / 未设 Key / 不可用 / 已停用 / 可升级）。状态取值与状态列 `channelHealth()` 一致，“可升级”取 `availableUpgrade()`。

### 3.3 渠道弹窗

| 项 | 说明 |
| --- | --- |
| 尺寸 | `sm:max-w-4xl`，`h-[min(88svh,800px)]`，`p-0 gap-0`，内部 头部 / 页签 / 滚动区 三段 |
| 头部 | 名称 `text-lg font-semibold` + `StatusLabel` + key（mono, muted）；右侧是行内操作（检查 · 导入 · 设置 Key · 删除；表格行里没有“检查”）和 `[×]`。导入、删除先关掉本弹窗再开对应弹窗（不叠着）；设置 Key 留在原地，设完概览立刻刷新 |
| 页签 | `ui/tabs`：概览 / 配置 / 模型 N。当前页签写进 URL `?tab=` |
| 概览 | 两列 `DescriptionList`：地址（可复制）、插件（链接到插件弹窗；有新版时后面跟文字链“升级到 vX” → 切到配置页签并展开高级设置）、API Key（已设置 / **未设置 · 设置**，“设置”打开设 Key 弹窗）、限流、当前负载、安全开关（内网 / 凭证用 `Tag tone=warning`，都没开写“均关闭”）、插件设置、最近修改。检查结果有时，在列表上方一行 `CheckResult`。**不再有任何 Notice 横幅** |
| 配置 | 原抽屉的表单原样搬进来（选平台 → 连接 → 名称 + 高级设置），底部固定栏 `[保存并检查]`；admin 为只读 |
| 模型 | `Segmented` 按能力筛选 + `[+ 新建模型]` + `ModelRows hideChannel`；去掉“点击模型直接打开编辑弹窗”的副标题 |
| 新建 | “新建渠道”打开同一弹窗，标题“新建渠道”，只有配置内容、没有页签；保存成功后变成该渠道的编辑态，出现页签，停在配置页签显示检查结果和“导入模型 / 新建模型”两个下一步 |
| 关闭 | 配置页有未保存修改时，关闭先确认“放弃修改？”（沿用抽屉现有逻辑）；切页签不丢表单（表单保持挂载） |

URL：`?key=<key>`（概览）、`?key=<key>&tab=config|models`、`?new=1[&plugin=<key>]`。旧链接兼容：`?edit=new` → 新建，`?edit=<key>` → 配置页签。

### 3.6 能力的中性样式（全后台）

`kind.tsx` 的 `KIND_STYLE` 直接用 Tag 的语气色（不新增 token）：文本 sky、图片 violet、视频 rose、音频 orange、Agent emerald；图标底 `bg-*-500/10`，图标 `text-*-700 dark:text-*-400`。

| 位置 | 支持 | 不支持 |
| --- | --- | --- |
| `KindIcons`（表格、版本历史） | `size-6 rounded-md`，图标 `size-3.5`，浅底 + 图标色 | `text-muted-foreground/30` |
| `KindTag`（模型表能力列） | `Tag tone=neutral`，只有图标带色，文字中性 | — |
| 插件弹窗能力卡片 | 卡片 `border bg-muted/40` 中性；图标块浅底 + 图标色；标题 `text-foreground`，模式 `text-muted-foreground` | `border-dashed`，整卡 `text-muted-foreground/50` |

变更：原为 Tag 的整块语气色（彩色底 + 彩色字 + 彩色整卡），现在只有图标带色。

## 4. 动效

| 触发 | 属性 | 时长 / 曲线 | 方向 |
| --- | --- | --- | --- |
| 打开弹窗 | opacity 0→1，scale 0.95→1；遮罩 opacity | 200ms，`ui/dialog` 默认 | 屏幕中心 |
| 关闭弹窗 | 反向 | 150ms（≈70%） | 回中心 |
| 切页签 | `ui/tabs` 默认：选中项底色换位；内容直接切换（配置页保持挂载，不丢未保存的修改） | `transition-all` 默认 | — |
| 表格能力筛选 | 选中浮块 `layoutId` 滑动（`Segmented` 的 `slideId`） | `SPRING` | 水平跟随 |
| 开关 | 滑块 transform | `ui/switch` 默认 | — |
| 检查按钮 | 图标换 Loader2 旋转（生成中类状态指示，允许循环） | 点下立即 | — |
| 状态列结果出现 | opacity 0→1 | `DURATION.base` | 原位 |
| 行内操作 hover | 底色 opacity | `DURATION.fast` | — |
| 按钮按下 | scale 0.96 | `TAP` | — |

`prefers-reduced-motion`：弹窗、菜单只淡入淡出（`ui` 组件已处理），页签指示条直接跳位。
