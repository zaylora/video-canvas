联动规则

三栏共享一个「选中项 + 当前时间」，所有联动都从它派生。

  • 左栏点一项 → 舞台换成它的视频，检查器换成它的拆解 / 脚本，时间归零。
  • 舞台播放 → 时间轴播放头走动，当前镜头段高亮；检查器当前镜头高亮并自动滚入视野。
  • 点时间轴的段或检查器的镜头 → 跳到该镜开始播放。点在输入框里不跳。
  • 「参考 n」 → 切到对比模式并定位；未出片时选中原片并跳到那一镜。
  • 对比模式 → 舞台两个视频并排同步（成片为主时钟），检查器自动切到「镜头对照」。
边界
  • 对比只能做到镜头级对齐，依赖成片实际节奏贴合脚本时间。未验证
  • 键盘快捷键在输入框聚焦时不响应。
  • 窄屏不做创作台，退回 v2 纵向布局。
