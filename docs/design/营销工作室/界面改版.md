## 1. 设计摘要

- **问题**（看截图与代码得出；用户认可内容本身，不满意的是呈现与交互）：
  1. **成片不是主角、不能直接播**：成片只是脚本卡左侧最宽 176px 的小框（`video-box.tsx`），要点开弹窗才能播放（`PlayerDialog`）。
  2. **参考原片看不到**：参考视频只在拆解卡头上有一个 36×48 的缩略图（`RefThumb`），拆解表写了「0–9.23s 双手托篮…」，却没法直接看那一段。
  3. **信息平铺但没有层次**：拆解表、脚本镜头都是同字号大段文字，标签、下拉、按钮混在一起，视觉上「挤」，读起来累。
  4. **没有和参考片对比的地方**：跟拍版像不像，只能靠记忆。
  5. **生成框挡住内容**：完整的 `MarketingComposer` 吸附在底部（`detail/index.tsx` 的 `sticky bottom-4`），压住拆解表和脚本。
- **推荐结论**：
  - **结构不变**：左栏事实卡 + 右侧轮次（轮次头、环节进度、参考拆解、脚本卡）。
  - **参考拆解变成「原片播放器 + 拆解」**：左边是能直接播放的原片，右边是整体分析；下面的镜头表**点哪一行，原片就跳到那一镜**，播放中当前镜头行自动高亮。
  - **脚本卡变成「成片播放器 + 完整脚本」**：成片放大到可直接播放；镜头列表全部保留，**点镜头 → 成片跳到那一镜**、播放时当前镜头高亮；「参考 n」点了打开对比层并定位到那一镜。底栏的配乐 / 音色、风险标签、方法、提示词、⋯、出片全部保留。
  - **对比层**：左原片、右成片同步播放 + 镜头对照轨；拆解在对比层里也能就地改。
  - **视觉**：清透层级——少框线、字号分三级、标签与下拉统一成小胶囊、留白加大；长内容加「收起 / 展开」，**默认展开**。
  - 生成框收成底部的「✦ 再写一轮」胶囊，点开才展开。

### 2.2 约束

- 页面上的信息项**一项不删**（用户 2026-11-12）。
- 只用现有接口和 store；出片进度沿用 `useTasksStore` 中 `node_id = mkt:{scriptId}` 的进行中任务。
- 出片仍要用户点击确认。
- 同步播放只能在浏览器里做：两个 `<video>`，一个主时钟。

### 2.3 缺口

- 原片、成片都不能在页面上直接播放、按镜头跳转。
- 没有对比组件和「成片时间 → 原片时间」的映射函数。

## 3. 用户与场景

- **用户**：电商卖家 / 运营。会认真读拆解和脚本（用户明确认可这些分析），但希望读起来不累、看片方便。
- **主任务**：上传 → 等脚本 → **对照原片读拆解** → 读 / 改脚本 → 出片 → **看片、对比原片** → 下载。
- **成功标准**（提案）：不打开任何弹窗就能看原片、看成片、按镜头跳转；从「看到拆解某一镜」到「看到原片这一镜」只需点一次。

**依赖框架**：同步播放与镜头联动用原生 `<video>` + 少量代码即可，**未发现值得引入的依赖**。

## 5. 设计原则

1. **信息全留，靠层级减负**：不删字段，用字号、颜色、留白和收起区分主次。（用户反馈）
2. **文字和画面联动**：凡是写了时间的镜头，点一下就能看到那一段画面。（目标 ②③）
3. **片在文字旁边**：成片、原片都在页面上直接播放，不必开弹窗。（目标 ③；Creatify 反例）
4. **清透少框**：沿用 chrome 令牌，一张卡内部不再画格子线。（编码规范 6.1）

### 6.2 左栏事实卡（内容不变）

- 素材缩略图：一行排列，悬停放大预览，左下角小标「商品 / 模特」。
- 商品名 `font-display` 18px + 右侧编辑笔（打开现有 `FactDialog`）。
- 四段（外观锚点 / 卖点 / 禁用说法 / 引导下单）：小标题 12px 灰 + 图标；条目 13px，行距 1.55，条目间 4px；每段间 18px。
- 每段超过 5 条时折叠为「+N 条」，点开展开（**默认值**）。
- 窄屏（<1024px）：左栏移到顶部，默认折叠成「可口可乐 · 外观锚点 4 · 卖点 2 …」一行，点开展开。

### 6.3 轮次头与环节进度（内容不变）

- 参数胶囊保留（平台、视频模型、画幅 · 分辨率 · 时长、旁白语言、参考时长），样式改为无底色的细描边小胶囊（`ring-1 ring-chrome-border h-6 text-xs`），降低视觉重量。
- 环节进度 `StepsBar` 保留，图标 + 环节名；改为更轻的样式（完成为绿色勾 + 正文色文字，进行中为转圈，失败为红色），悬停仍显示方法。
- 写脚本中：环节进度旁加一句当前阶段文字（沿用 `round.stage`）+「取消」。

### 6.4 参考拆解卡（字段全部保留，加原片播放器）

**头部（始终显示）**

- 左：原片播放器。宽 120px、按原片画幅（竖版高 213px），圆角 14px；**点击直接在原位播放**（带声音），再点暂停；右下角「全屏」小图标打开播放层。
- 右：
  - 第一行：「参考拆解」（15px 粗体）· N 个镜头 · 时长 · 方法：xxx（灰）；右侧风险标签「第三方品牌 N」「原片背书 N」（悬停列出原文）+ 收起 / 展开按钮。
  - 第二行：🔥 为什么火（`why_viral`，13.5px，最多 2 行，展开态全文）。
  - 第三行：整体风格与叙事（`style` + `narrative_arc`，13px 灰，展开态显示）。
- 默认**展开**（v1 默认折叠，用户希望内容都在）。

**镜头表（展开态）**

每个镜头一行，**行本身可点击**（点在非输入区域）→ 原片跳到 `start` 并播放；播放过程中当前镜头行左侧出现 3px `bg-beam` 竖条并加浅底。

| 列 | 宽度 | 内容（全部保留） |
| --- | --- | --- |
| 时间 | 96px | `0–9.23s`（等宽数字）；`景别 · 运镜`（灰）；「前 3 秒」标签 |
| 主体 + 动作 | 弹性 | 小标题「主体 + 动作」11px 灰；正文 14px 可改（`EditableText`） |
| 台词 | 弹性 | 小标题「台词」；正文 13.5px 可改 |
| 关键颜色 | — | 正文下方一排小胶囊，可增删（沿用现有逻辑） |
| 商品怎么出现 | 200px | 小标题；下拉（`productRole`）改成胶囊式下拉；下方灰字 `productInFrame` 说明 |

- 行与行之间不画线，用 8px 间距 + 悬停浅底区分。
- 底栏：「原片背书：…」原文（12px 灰，可展开）｜「恢复原稿」（`reverseEdited` 时）｜「按拆解重写跟拍版 ✦N」（`reverseDirty` 时；跟拍版出片中禁用并写原因）。
- 拆解失败：卡片位置显示原因 +「重试拆解」（沿用 `FailedLine`）。

### 6.5 脚本卡（内容全部保留，成片可直接播）

**布局**：`grid-cols-[auto_1fr]`，左成片、右脚本；窄屏上下排列。

**左：成片播放器**

- 竖版宽 220px（原 ≤176px），横版宽 360px；按轮次画幅。
- 各状态沿用 `video-box.tsx`：待出片（商品图模糊底 +「还没出片」）、重写中、出片中（环形进度）、失败（原因）、已出片。
- **已出片：原位播放**（点击播放 / 暂停，带进度条与声音），不再弹窗；右下角「全屏」打开播放层。
- 多条成片：播放器下方「第 1 条 / 第 2 条」分段按钮（原来是画面上的小圆点）。
- 播放器下方：「对比原片」胶囊按钮（本轮有参考片且已出片时显示）。

**右：完整脚本**

- 头部：角度标签（跟拍为 `text-beam` +复制图标）、状态、「已修改」；标题 16px 粗体；钩子 `hook`（若有，13.5px，左侧 2px `bg-beam` 竖线）。
- 镜头列表，每镜一行（**全部保留**）：
  - 左 96px：`0–9.33s`、`景别 · 运镜`、「参考 n」胶囊（跟拍版）。
  - 右：画面描述 `scene`（14px 正文色），下面是旁白（麦克风图标 + `EditableText`，13.5px 粗体；有风险时描红，下方红色小字写原因）。
  - **点镜头行（非输入区域）→ 成片跳到该镜 `start` 并播放**；播放中当前镜头左侧 3px `bg-beam` 竖条 + 浅底。
  - **「参考 n」点击 → 打开对比层并定位到这一镜**（未出片时：打开参考拆解卡并滚动、高亮参考镜头 n，原片跳过去）。
- 底栏（全部保留）：配乐 · 音色（灰，截断，悬停全文）｜风险标签｜方法：xxx｜「提示词」｜⋯（下载成片 / 发到画布精修 / 恢复原稿）｜「出片 / 重出 ✦N」实心胶囊。

### 6.6 播放层

- 由「全屏」图标打开，取代 `PlayerDialog`：深色遮罩 `bg-black/85 backdrop-blur`，视频按画幅撑满；底部「第 N 条」切换、「对比原片」、「下载」；Esc 关闭；左右键切到本轮上一 / 下一条已出片（**默认值**）。

### 6.7 对比层

**入口**：脚本卡的「对比原片」、「参考 n」、播放层的「对比原片」。条件：本轮有 `refVideo` 且脚本已出片。

- **布局**：左右并排（窄屏上下），两个视频等高，取可用高度的 55%。
- **主时钟 = 成片**；一个播放键、一条按成片时间刻度的进度条。
- **时间映射**（纯函数 `refTimeAt(t, script, reverse, refDuration)`）：
  - 跟拍版且镜头有 `refShot`：成片时间 t 所在镜头 i 对应参考镜头 r，分段线性映射 `ref = r.start + (t − start_i) / (end_i − start_i) × (r.end − r.start)`。
  - 改编版或缺映射：按比例 `ref = t × refDuration / scriptDuration`。
  - 结果夹在 `[0, refDuration − 0.05]`。
- **同步**：原片 `playbackRate` = 当前镜头时长比（夹在 0.5–2.0）；每 250ms 校正，偏差 >0.15s 直接 seek；拖动、点镜头时两边一起 seek；任一边缓冲时两边一起暂停。
- **声音**：默认只开成片；「原片 | 成片」切换，不同时出声。
- **镜头对照轨**：按成片镜头分段，宽度与时长成正比；跟拍版每段标「原片 n」；点段两边跳转。
- **镜头对照面板**：左「原片 · 镜头 n」（主体 + 动作、台词可改，「更多」里是商品怎么出现与关键颜色；前 3 秒标签）；右「成片 · 镜头 n」（画面、旁白只读，「去改」→ 关闭对比层并滚动到脚本卡对应镜头、聚焦旁白）。改编版左侧只读。
- 拆解有改动时底部出现「恢复原稿」「按原片重写跟拍版 ✦N」，与拆解卡底栏同一份状态。
- 面板标题右侧一行灰字：原片含第三方品牌 / 背书数量。

### 6.8 「再写一轮」胶囊

## 7. 状态与异常

| 场景 | 表现 |
| --- | --- |
| 加载中 / 加载失败 | 沿用现有 |
| 写脚本中 | 环节进度 + 阶段文字 + 取消；拆解卡、脚本卡骨架（拆解卡骨架里原片播放器已可播放） |
| 轮次失败 / 已取消 | 沿用现有（红色行 + 重试 / 灰色行） |
| 环节失败 | 沿用 `FailedLine`，放在对应卡片位置 |
| 拆解失败 | 拆解卡位置显示原因 +「重试拆解」；原片播放器仍可播放 |
| 旁白有风险 | 描红 + 原因小字；出片按钮禁用并写原因（沿用 `scriptRenderState`） |
| 余额不足 | 出片、全部出片、重写禁用，`title`「积分不足」 |
| 编辑冲突 68009 | 沿用 |
| 视频加载失败 | 播放器内显示「视频加载失败」+「重试」；对比层一边失败时另一边可单独播放 |
| 原片地址失效 | 原片播放器显示「原片无法播放」；对比入口禁用并写原因；镜头行点击只高亮不跳转 |
| 编辑中点镜头行 | 点在输入框 / 下拉 / 标签里不触发跳转；只有点行的空白处或时间列才跳转 |
