# 任务书 · 前端：营销工作室 + 后台环节技能页

> 设计依据：`营销工作室.md` §6.1–§6.8、§6.10、§6.11、§7.3；接口形状以 `接口契约.md` 为准；**界面照两份高保真原型**：`营销工作室原型.html`（用户端）、`环节技能-后台原型.html`（后台）。原型里的布局、文案、状态、禁用原因就是验收标准。
> 后端同时在开发，接口暂时不可用：按契约写 API 层和类型，纯逻辑写单元测试；页面能在没有后端时渲染空 / 错误状态即可。

## 要做的

1. **API 层** `web/src/api/marketing/`（用户端）与 `web/src/api/admin/steps/`（后台）：类型、snake → camel 映射、全部接口函数。
2. **入口**：侧栏 NAV 在「短剧工作室」后加「营销工作室」（`ShoppingBag`，`badge: "New"`，`/marketing`）；路由 `/marketing`、`/marketing/:id` 挂在 `HomeLayout` 下。后台 `admin-nav.ts` 在「技能」后加「环节技能」（`agent/steps`，图标 `Workflow`）并更新它的测试；后台路由。
3. **列表页** `/marketing`：标题、营销生成框、「我的营销片」卡片网格（状态行 + 底部状态条）、悬停菜单（打开 / 删除确认）、空状态。
4. **营销生成框** `components/marketing/marketing-composer.tsx` + `store/marketing-composer.ts`（不要复用首页 `useComposerStore`）：商品 / 模特 / 参考三个上传块（参考块在模型不收视频时禁用并写原因；时长超限提示）、描述、平台菜单、角度菜单（无参考：自动 ×1–4 或多选内置角度；有参考：跟拍固定 1 份 + 改编 0–3）、视频模型菜单（无 omni 的禁用并写原因）、参数弹层（画幅 / 分辨率 / 时长 / 旁白语言 / 文本模型，只列能看图的）、写脚本预估积分（`POST /marketing/quote`）、圆形发送键、状态行。在详情页底部作为 dock 复用（商品图固定）。
5. **详情页** `/marketing/:id`：左栏商品卡（事实卡四段 + 编辑弹窗）；轮次倒序：轮次头（设置标签 + 全部出片）、环节进度条（四个环节小标签与状态）、取消、失败行与重试、警告行；**参考拆解卡**（折叠摘要：镜头数、为什么火、品牌 / 背书提示；展开镜头表可改动作 / 台词 / 商品出现方式，失焦保存；恢复原稿；按拆解重写跟拍版）；**脚本卡**（成片区各状态、多条切换、播放；角度 / 跟拍标签、状态、已修改；镜头列表与旁白输入，失焦或回车保存，问题旁白描红；问题标签、方法小字、提示词弹窗、更多菜单：下载 / 发到画布 / 恢复原稿、出片 / 重出带积分）；环节失败卡。
6. **实时**：处理 `marketing.round`、`marketing.script`，以及 `task.updated` 中 `node_id` 以 `mkt:` 开头的进度；toast 策略与侧栏「进行中」认 `mkt:`；重连后重新拉详情。
7. **后台环节技能页**：列表（营销四行、短剧灰显待迁移、格式化器只读三行与预览）、技能停用退回内置的提示条、详情抽屉三个标签（协议只读 / 方法：当前绑定、候选列表含版本选择与「仅用正文」「会截断」「已停用」、绑定历史与恢复 / 试跑：样例、文本模型、对比勾选、运行后轮询 `GET /admin/step-trials/:id`、两列结果、「设为生效」仅在候选通过时可点 + 确认弹窗）。
8. 发到画布成功后在新标签打开画布（画布路由照现有）。
