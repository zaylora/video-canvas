# 营销工作室详情页：创作台布局（v3 备选）

> - **范围**：营销片详情页 `/marketing/:id` 的另一种布局。用户 2026-11-12 提出：「能不能像创作台一样，而不是一直无限滚动下拉」。**信息项与 [界面改版.md](界面改版.md)（v2）完全一致**（事实卡、环节进度、参考拆解全部字段、脚本全部镜头、方法、提示词、风险标签），交互沿用 v2 的原位播放、镜头联动、原片对比；**只换布局**：从「整页纵向滚动」改成「一屏固定的三栏工作台」。
> - **日期 / 状态**：2026-11-12 · 用户选定 v3 创作台，已实现未提交（`scripts/check.sh` 全过），未在浏览器与真实成片上验收。v2 纵向方案搁置。
> - **证据约定**：同 v2；本文全部为**提案**，未实现。不改后端、不改接口、不改出片流程。
> - **配套演示**：[创作台-演示.html](创作台-演示.html)。

## 1. 设计摘要

- **问题**：v2 把所有轮次、拆解、脚本纵向堆叠，3 份脚本 + 拆解就要滚好几屏；看第 3 份脚本时，原片和事实卡都已滚出视野，对照困难。
- **结论**：做成剪辑软件式的**创作台**——页面高度固定为视口，四块区域各自内部滚动：
  - **顶栏**：返回、商品名、**轮次切换**、本轮参数、环节进度、全部出片、再写一轮。
  - **左栏「素材与成片」**：本轮的原片 + 每份脚本一行（小缩略图、角度、标题、状态）；下面是可折叠的商品事实卡。
  - **中间「舞台」**：选中项的大播放器 + 走带控件 + **镜头时间轴**；可切到「对比原片」，两个视频并排、两条时间轴对齐。
  - **右栏「检查器」**：选中脚本时是完整脚本（镜头列表可改旁白）与提示词；选中原片时是参考拆解全部字段；对比模式下多一个「镜头对照」页。底部固定操作条（出片 / 重写跟拍版等）。
- 一次只看一份脚本（或原片），但**切换只需点左栏一下或按 ↑↓**，原片和事实卡始终在左栏可见。

## 2. 用户与场景

- 和 v2 相同：电商卖家 / 运营，会认真读拆解和脚本。
- 创作台更适合「逐条精看、对照、修改」；v2 更适合「一屏扫完全部脚本」。两者取舍见 §6。

## 3. 布局规格

```
├左栏 248px──────┬舞台（弹性）─────────────────────────────┬检查器 400px────────────────┤
│ 本轮           │        [单看 | 对比原片]  [第1条|第2条] ⛶ │ 跟拍 · 已出片 · 已修改      │
│ ▣ 原片 14.8s   │                                          │ 可口可乐瓶身细节跟拍        │
│ ▣ 跟拍 ●       │            ┌──────────┐                  │ [脚本][提示词][镜头对照]    │
│ ▣ 痛点-解决 ⚠  │            │   成片   │                  │ 0–9.33s 中景转近景·固定微调 │
│ ▣ 卖点 62%     │            │          │                  │ [参考1] 画面…               │
│ ▣ 生活方式 ✕   │            └──────────┘                  │ 🎙 旁白（可改）             │
│                │ ▶ 00:04.2/00:15 ━━━━●━━━━━━━━━━━━━━━━━━  │ 9.33–11.93s …（当前镜高亮） │
│ ─ 商品信息 ✎ ─ │ [镜1 · 原片1     ][镜2·原片2][镜3·原片3] │                             │
│ 外观锚点 …     │                                          │ ♫配乐·音色 方法 ⋯ [重出✦90] │
│ 卖点 / 禁用 …  │                                          │                             │

```

- 整页 `h-dvh overflow-hidden`；左栏、检查器、舞台各自 `overflow-y-auto`。最小宽度 1280px 时三栏全显；1024–1279px 检查器收为 360px；<1024px 左栏收成抽屉（顶栏左侧按钮打开），检查器移到舞台下方并恢复整页滚动（窄屏不做创作台）。
- 三栏都是清透卡（`bg-chrome ring-chrome-border backdrop-blur-xl rounded-3xl`），栏间距 12px，外边距 12px。

### 3.1 顶栏

| 元素 | 规则 |
| --- | --- |
| 返回 + 商品名 | 商品名旁的笔打开事实卡编辑弹窗（`FactDialog`） |
| 轮次切换 | 分段按钮「第 N 轮」，最新在左；写脚本中的轮次带转圈；超过 5 轮折成下拉。切轮次时左栏、舞台、检查器一起换，默认选中该轮第一份已出片的脚本，没有则选原片，再没有选第一份脚本 |
| 本轮参数 | 细描边小胶囊（平台、视频模型、画幅 · 分辨率 · 时长、旁白语言、参考时长） |
| 环节进度 | 图标 + 名称（事实卡 / 拆解 › 跟拍 / 创意），悬停显示方法；写脚本中时后面跟阶段文字和「取消」 |
| 全部出片 | 本轮 ≥2 份可出片时显示 |
| 再写一轮 | 打开下拉面板（640px），里面是完整 `MarketingComposer`，沿用当前轮设置；发送后新轮次出现在轮次切换最左并选中 |

### 3.2 左栏「素材与成片」

- **列表项**（高 76px）：左 36×64 缩略图（原片 / 成片首帧；未出片为商品图模糊底）；中间角度名（跟拍为 `text-beam`）+ 标题一行截断；右侧状态：已出片绿点（多条显示「×2」）、待出片灰点、出片中百分比、重写中转圈、失败红叉、旁白有风险黄色三角。
- 第一项是「原片」（有参考时），副标题「N 个镜头 · 时长」。环节失败的那份显示为虚线项「前后对比版生成失败 · 重试」。
- 选中项：浅底 + 左侧 3px `bg-beam` 竖条。↑↓ 键切换。
- **商品信息**（列表下方，可折叠，默认展开）：缩略图、外观锚点 / 卖点 / 禁用说法 / 引导下单；每段超过 4 条折叠为「+N」。

### 3.3 舞台

- **单看模式**：选中项的播放器，按画幅尽量撑满舞台高度（上下留出走带区）。
  - 原片：直接播放。
  - 脚本已出片：播放成片；右上角「第 1 条 / 第 2 条」、全屏、下载。
  - 脚本未出片：舞台中央是状态卡——待出片（大号「出片 ✦N」；有风险时为「先改标红的旁白」并禁用）、出片中（环形进度）、重写中、失败（原因 +「重试 ✦N」）。
- **对比原片模式**（分段按钮「单看 | 对比原片」，仅本轮有参考且脚本已出片时可选，否则禁用并写原因）：两个视频并排，同步规则同 v2 §6.7（成片为主时钟，跟拍按 `refShot` 分段线性映射，原片按镜头时长比变速，250ms 校正，声音二选一）。
- **走带**：播放 / 暂停、时间、进度条。
- **镜头时间轴**：按镜头分段、宽度与时长成正比，段内写「镜 n」与镜头摘要；跟拍版每段下方写「原片 n」。播放头跟随；点段跳转。对比模式下显示两条：上「原片」、下「成片」，当前对应的两段同时高亮，中间用细线连接对应关系。
- **键盘**：空格播放 / 暂停；← → 上一镜 / 下一镜；C 切换对比；F 全屏；↑ ↓ 切换左栏项。输入框聚焦时不响应。

### 3.4 检查器

| 选中 | 标签页 | 内容（与 v2 一致） |
| --- | --- | --- |
| 原片 | 拆解 | 方法、第三方品牌 / 原片背书标签（悬停原文）、为什么火、风格与叙事；镜头列表：时间、景别 · 运镜、前 3 秒、主体 + 动作（可改）、台词（可改）、关键颜色、商品怎么出现下拉 + 说明 |
| 脚本 | 脚本 | 角度、状态、已修改、标题、钩子；镜头列表：时间、景别 · 运镜、参考 n、画面、旁白（可改，风险描红 + 原因） |
| 脚本 | 提示词 | 格式化后的视频提示词全文（只读，等宽字体）+ 复制 |
| 脚本（对比模式） | 镜头对照 | 当前镜头：左原片（动作 / 台词可改，商品怎么出现）、右成片（画面 / 旁白，「去改」切到脚本页并聚焦旁白）；改编版原片只读 |

- 镜头列表与舞台联动：播放时当前镜头高亮并自动滚入视野（用户手动滚动后 3 秒内不自动滚）；点镜头（非输入区）→ 舞台跳转。「参考 n」→ 切到对比模式并定位（未出片时：选中原片并跳到那一镜）。
- **底部操作条**（固定）：
  - 脚本：配乐 · 音色、风险标签、方法、⋯（下载 / 发到画布精修 / 恢复原稿）、「出片 / 重出 ✦N」。
  - 原片：原片背书原文（一行截断，悬停全文）、恢复原稿、「按拆解重写跟拍版 ✦N」。

## 4. 状态与异常

沿用 v2 §7，位置调整：

| 场景 | 位置 |
| --- | --- |
| 写脚本中 | 顶栏轮次带转圈 + 环节进度与阶段文字；左栏为骨架项；舞台显示原片（若有）或「正在写脚本」状态卡；检查器骨架 |
| 轮次失败 / 已取消 | 舞台状态卡（原因 + 重试 / 已取消），左栏为空 |
| 环节失败 | 左栏虚线项 + 重试 |
| 拆解失败 | 左栏原片项带红叉；检查器拆解页显示原因 +「重试拆解」，原片仍可播放 |
| 选中项被删除 / 轮次切换 | 自动选中默认项（§3.1 规则） |

## 6. 与 v2 的取舍

| 维度 | v2 纵向 | v3 创作台 |
| --- | --- | --- |
| 一屏扫完全部脚本 | 好 | 差：一次看一份 |
| 精看、对照、修改 | 中：原片和事实卡会滚出视野 | **好：原片、事实卡、脚本、播放器同屏** |

| 多轮次 | 纵向堆叠 | 顶栏切换 |

| 实现量 | 中 | 中偏大（新外壳 + 时间轴） |

- **与设计的出入**：
  - 「再写一轮」做成顶栏按钮 + 右上浮层面板（受控，关闭按钮 / Esc / 发送成功后收起），不用 Popover——生成框里的下拉菜单会被 Popover 当成外部点击而关掉面板。
  - 全屏用浏览器原生 Fullscreen API 作用在舞台视频区，不另做全屏播放层。
  - 原型里的提示性小字（如「脚本在右侧，看好了再出片」）按编码规范 6.2 未实现。
  - 卖点图标由 `Sparkles` 换为 `BadgeCheck`；积分单位符号 `Sparkle`/✦ 保留（全站统一）。
- **舞台改为剪辑软件式（2026-11-12 用户反馈「应该像剪辑那种工作台，但是不可以剪辑，只是播放用的」）**：
  - 监视器：画面上只留暂停时的大播放键与缓冲转圈，点画面播放 / 暂停；不在画面上叠控制条（窄视频上进度条会被挤得看不见）。
  - 走带条（监视器下方）：上一镜、播放 / 暂停、下一镜、时间码、「镜 n / 共 m」、静音（对比时不显示，声音二选一）、全屏。
  - 只读时间轴：左侧轨道名，顶部秒刻度尺（约 8–16 格），只有一条连续的灰色轨道（用户 2026-11-12：「就一条轨道就好了」「不需要里面的文字内容，也不需要分段，改成灰色」），播放过的部分稍亮，对比时也不加原片轨；镜头信息看右侧检查器与走带条的「镜 n / 共 m」；一根播放头竖线贯穿所有轨道。在刻度尺或轨道上按下即移动播放头，按住拖动来回看；片段不能拖、不能剪。取代了 §3.3 原先的「镜头时间轴按钮条」和其后试过的「分段进度条」。
- **后续调整（2026-11-12 用户逐项反馈）**：
  - 三栏可拖动调宽（≥1024px，`react-resizable-panels`，与短剧片场同款）：左栏默认 248px（200px–35%）、检查器默认 400px（300px–45%）、舞台最小 360px；拖好的宽度记在本机（`marketing-workbench-columns`）。
  - 左栏被滚动条遮挡：滚动区预留滚动条位置、禁止横向滚动；时长统一一位小数（`formatSeconds`，14.833 → 14.8s）。
  - 圆角改为苹果式连续曲率（CSS `corner-shape: squircle`，只作用在创作台内，胶囊不变，不支持的浏览器退回普通圆角）；半径按嵌套递减：外层三栏 28px、顶栏与视频 22px、内部块 18–20px。
  - 对比原片改为两个视频各自正常播放（用户：「两个都是正常的视频播放就好了，不需要强行一致」）：只联动一起播放 / 暂停，在成片上定位时原片跳到同一时间点；去掉按镜头映射变速和每 250ms 校正（原实现会触发「跳转 → 缓冲 → 暂停成片 → 再播放 → 再跳转」的循环，原片一卡一卡）。§3.3 中「同步规则同 v2 §6.7」作废。
  - 监视器改用画布与短剧工作室共用的 `VideoPlayer`（用户：「改成正常的视频播放器，复用组件」）：自写的视频、播放键遮罩和走带条（上一镜 / 下一镜 / 时间码 / 静音 / 全屏）去掉，播放、进度、静音都在共享播放器里。为了让下方时间轴、检查器高亮与跳转继续工作，给 `VideoPlayer` 加了两个可选参数：`onVideo`（video 元素挂上 / 卸下时通知外部）、`playSignal`（数值变化且停在封面时开始播放）；画布、短剧的现有用法不受影响。播放器停在封面时点时间轴或镜头：先记下位置、让播放器开始播放，video 挂上后再跳。对比时两边都是共享播放器。
  - 去掉播放器下方的时间轴（用户：「这个不要了」）：进度看共享播放器自带的进度条；镜头定位靠右侧检查器点镜头与键盘 ← →。
  - **去掉对比原片**（用户：去掉「单看 / 对比原片」，整个去掉对比）：舞台只放一个共享播放器；检查器只剩「脚本 / 提示词」两页（「镜头对照」删除）；C 键删除；「参考 n」改为选中原片并跳到那一镜。删掉 `compareState`、`refTimeAt` 与 store 里的模式、声音、聚焦状态。§3.3 对比模式、§3.4 镜头对照页均作废。
  - 「出片中」加动画：按成片画幅画生成中的画框，一道光慢慢扫过；拿到进度前进度环一段弧转圈，之后按百分比平滑填满；系统减少动效时关闭。
