## 要做的

1. **四个环节**（`backend/internal/marketing/`，注册到 stepkit）：`marketing.facts`、`marketing.reverse`、`marketing.follow`、`marketing.create`。输入、输出 Schema、硬校验 / 软问题照设计 §6.10 与 `环节技能-后台原型.html` 里的协议标签。内置方法正文写在 `internal/marketing/methods/*.md`（改写自 daihuo-fanpai MIT、HiAPIAI MIT、tvc-director MIT、Creatify MIT、YouMind CC BY，`methods/NOTICE.md` 署名）。每个环节提供试跑样例（见下「样例素材」）。
2. **规则**：平台预设（契约 §1.1 的 7 个平台：默认画幅、语言、写法要点、额外禁令）、广告法极限词清单 `internal/marketing/rules/zh_forbidden.txt`；软问题扫描函数（forbidden / claim / brand），`PUT` 改旁白时复用。
3. **格式化器** `internal/marketing/format/`：`VideoFormatter` 接口，`seedance`（分区块，模板见设计 §6.6）与 `generic`（段落），`h3` 用 generic；纯函数；超长按设计删减，仍超 68008。实现 `GET /admin/formatters`。
4. **迁移 `0035_marketing.sql`**：`marketing_projects`、`marketing_rounds`（含 reverse / reverse_original / reverse_revision / 当前跟拍据以写成的拆解快照）、`marketing_step_runs`、`marketing_scripts`（含 kind、follow_map、flags、original、task_ids、revision）；`credit_ledger` 加 `marketing_step_run_id`。
5. **轮次编排** River job `marketing_round`：第一层 facts（项目已有事实卡 → `reused`）∥ reverse（有参考视频）；第二层 follow（reverse 成功）∥ create；环节失败互不拖累（设计 §7.1）；按环节冻结 / 结算积分；stage 文案；推 `marketing.round`。拆解看视频：所用文本模型 `Video=true` 时内联视频，否则退回 `Vision` + 截帧（新增 `videoframe.Cuts` 场景检测；切点各 1 帧 + 每秒 2 帧，上限 32），并加警告「拆解未包含声音，台词按画面推断」；都不可用时 reverse 失败。文本模型选择：用户选的模型不满足环节能力时用第一个满足的 Agent 模型，都没有 68003。
6. **用户端接口**：契约 §3 全部（含 `/marketing/options`、`/marketing/quote`、拆解编辑 / 恢复 / 重写跟拍、环节重试、脚本编辑 / 恢复 / 提示词预览 / 出片 / 全部出片 / 发到画布、项目增删改查）。出片：后端用格式化器拼提示词，以 `node_id = mkt:{脚本id}` 调现有生成任务创建（op=omni，图片 = 商品图 + 模特图，视频 = 参考视频，`generate_audio=true`），在 `generation_task_create.go` 加 `mkt:` 分支（锁脚本行、校验归属与状态，照 `seg:`）；任务结束回写脚本状态并推 `marketing.script`。flags 非空拒绝出片。
7. **发到画布**：用 canvasgraph 新建画布写素材节点、成片节点、每镜未生成视频节点并连线（设计 §6.7）；做不到的部分在报告里写明。
8. **fail_rate_7d**：给后端 1 留的统计口子接上 `marketing_step_runs`。
9. 错误码 68001–68011、68015、68016；WS 类型 `marketing.round`、`marketing.script`；路由、装配、`backend/README.md`。
