Agent 视频理解

让 Agent 看视频时也听懂声音

现在 canvas_inspect_video 只抽 6 帧，没有音轨。实测里唯一能把视频连同声音交给模型的路径是 Gemini 原生接口，而 Agent 只会说 OpenAI 格式。所以分两步：先让 Agent 模型能选 Gemini 接口格式，再给 Gemini 格式的模型加 「看视频」能力。设计稿 v3 · 未实现 · 2026-10-27

两个 PR

PR1Gemini 接口格式
  • 后台 Agent 模型选「接口格式」：OpenAI（默认）/ Gemini
  • Go 网关翻译：pi 的 OpenAI 请求 → Gemini streamGenerateContent，响应翻译回 OpenAI 行
  • pi（Node）不动；计费、限流、SSRF、留存沿用
  • 独立可用：Gemini 模型可以直接当 Agent 用
PR2看视频（依赖 PR1）
  • 能力新增「看视频」，只有 Gemini 格式能开
  • canvas_inspect_video 用当前模型发一次带视频的子请求，拿回画面 + 声音的中文分析
  • 失败退回抽帧，注明「音频未分析」
  • 后台识别建议 + 用户侧模型列表带 video

已确认的决定

问题决定
谁能看视频开了「看视频」的模型；不能看视频的不能用
在哪配后台模型配置统一管理，不加环境变量、不另起服务
视频怎么传对象存储传 URL（fileData），本地存储传 Base64（inlineData）
接口格式加 Gemini；不做成协议插件（Agent 不能用插件）；Claude 本期不做
看视频与格式只给 Gemini 格式（OpenAI 的 video_url 实测收不到视频）
可配置项与缓存先不加（只留一个 20MB 的内存保护常量）
生产有 Gemini 原生服务

仍需你确认

  • 生产 Gemini 服务的接入方式：base_url 形态（有没有 /antigravity 这类前缀）、鉴权认 x-goog-api-key 还是 Bearer（设计是两个都发）。
  • 子请求计费：按当前模型 Token 价照常扣、计入本轮已花积分（默认）。
  • 含人声对白的样本：测试视频很可能没有对白，需要再给一个。
  • 画布模型菜单要不要给能看视频的模型加标记（默认不加）。

实测：哪些行，哪些不行

来自你分享的 ChatGPT 对话（2026-10-27）。测试中转 api.vbing.site，模型 gemini-3.8-flash，样本 9,353,686 字节（「少年闰土月下刺猹」）。

调用方式结果结论
/antigravity/v1beta/…:generateContent + fileData（URL）17.5 秒，2,466 tokens，画面描述与分段时间戳能
同一路径 + inlineData（Base64）25.7 秒，2,677 tokens；模型自述「轻柔背景音乐、无对白、无字幕」（未独立核对）能
普通 /v1beta/…400 API key group platform is not gemini路径不对
OpenAI 兼容 chat/completions + video_url200，但模型说没收到视频（590 tokens）不能
其他早期尝试（非 /antigravity 路径）200 但没收到视频，或返回未声明的 workspace:listFiles 工具调用不能
HTTP 200 不代表视频被转发。判断成功要看返回里有没有视频内容；真机测试必须照这个标准。
Sub2API #7859（丢音频）、#7583（丢 PDF）说明兼容接口会静默丢多媒体，但不能断定视频丢失的根因。样本很可能没有人声，对白识别还没测过。

PR1 Gemini 接口格式

Gemini 的响应先翻译成 OpenAI 的 SSE 行，再交给现有的解析和透传。用量、取消、断流、重试全部复用，pi 看到的和 OpenAI 渠道一模一样。

pi（Node）OpenAI 请求，不改
SanitizeRaw白名单、强制用量、封顶输出（沿用）
toGemini（新）消息、图片、工具、schema 清洗
Gemini 渠道streamGenerateContent?alt=sse
fromGemini（新）逐块翻回 OpenAI 行 → 现有 accumulator / raw

    子请求的计费与留存

    流程复用 Preflight → Begin → SettleExternal，用途记为 video
    扣费按当前模型 Token 价照常扣，计入本轮已花积分；不算进上下文大小（RunModelUsage 只看 main）
    预检提示词字数 + 视频时长 × 约 300 token/秒 的估算 未验证；实扣以上游用量为准
    留存记 OpenAI 形状的请求体，媒体字段被现有脱敏替换成「[已省略 N 字符]」；不记翻译后的 Gemini 体（fileUri 不在脱敏键名里）
