设计修正（2026-10-25）

          

            最初打算在阶段 1 按 tool_call_id 去重，防止崩溃后重复写画布。读代码后发现，现在续跑时模型会重新生成调用，id 是新的，这样去重挡不住。
            现在拆成两步：阶段 1 改为每个工具结果出来就保存历史，让续跑时模型看得到已经做过的事；阶段 3 之前再让写工具按 tool_call_id 幂等，
            这是在 Pi Durable 里把写工具声明为可以重放的前提。设计文档的 2.3、8.2 节已同步修改。
