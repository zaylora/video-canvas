## A. 画布 Agent（拆分重构）

准备：`docker compose -f docker-compose.dev.yml up -d`（先在宿主机 `agent/` 下 `npm ci`），等 `agent`、`backend` 都 healthy；后台「AI 配置」里发布一个 agent 类型的模型。

### A1. 基本使用

- [ ] 新建 Agent 会话，发一条消息，能流式出字、有思考内容、有最终回复
- [ ] 让它「建一个组，里面放两个图片节点，并连线」：画布上节点和连线出现，工具行有名称和摘要
- [ ] 让它一次创建 6 个节点并连线：能完成（可能走 codemode 脚本）
- [ ] 让它删除一个节点：先出审批，**批准前画布不变**，批准后节点被删，Agent 接着总结
- [ ] 删除审批点「拒绝」并写说明：节点保留，Agent 看到说明
- [ ] 让它「先问我要几个镜头再动手」：出提问卡片，回答后继续
- [ ] 运行中追加一条消息（插话）：下一轮能看到
- [ ] 运行中点「停止」：状态变为已停止，已完成的画布改动保留
- [ ] 点「撤销本轮」：画布恢复；再点一次提示已撤销
- [ ] 点 👍 / 👎（点踩带原因），刷新页面后评价还在，取消评价也正常

### A2. 重启与恢复（拆分的核心价值）

- [ ] 运行中（模型正在输出）执行 `docker compose restart agent`：几秒后界面显示「恢复中」，随后继续并完成；**没有重复扣积分、没有重复改画布**
- [ ] 运行中执行 `docker compose restart backend`：运行不中断，backend 起来后继续
- [ ] 停掉 agent 超过 5 分钟再启动：未完成的运行变为「已中断」，点「继续」能接着跑
- [ ] agent 停着时发请求：画布里提示「Agent 暂不可用」，而不是一直转圈
- [ ] 等审批的运行：重启 agent 后审批卡片还在，批准后能继续

### A3. 计费

- [ ] 一轮运行后，积分流水里每次模型调用都有记录，余额变化与记录一致
- [ ] 流式中途「停止」：已产生的部分照样计费（取消时的用量是估的，偏高，属已知取舍）
- [ ] 生成类审批：批准的张数只能少不能多，超出本轮预算会被拒绝

### A4. 输出被截断

- [ ] 在后台把某个 agent 模型的「最大输出」临时调得很小（如 300），让它写长文：运行**失败**并提示「回答被截断…调大输出上限」，已写出的部分保留（改回去）

### A5. 后台观测

- [ ] 「运行记录」列表里能看到刚才的运行（结束后最多约 10 秒出现），状态、模型、工具数、积分正确
- [ ] 点踩、撤销之后再等几秒，列表里的评价和「被撤销」标记更新；按评价筛选能命中
- [ ] 导出一次运行（Markdown 和 JSON）：有用户请求、事件、工具调用（含参数和结果）、模型调用、审批、评价
- [ ] 版本对比 / 统计页面有数据
- [ ] 切换前的旧运行（如果有）仍能看到和导出

### A6. 开关与配置

- [ ] `.env` 设 `APP_AGENT_ENABLED=false` 后重启 backend：Agent 提示「暂不可用」，其它功能正常
- [ ] 故意把 agent 的 `AGENT_ID_KEY` 设成和 backend 不同：agent 容器变 unhealthy，日志里说明怎么改（验完改回）
- [ ] 旧 `.env` 里残留 `APP_AGENT_RUNTIME=process` 等：backend 能正常启动（被忽略）

## B. 画布导入 / 导出（master 新增）

准备：两个账号 A、B；账号 A 的画布里有文本、图片、视频节点、分组、连线、角色卡节点和 `@` 引用提示词。

### B1. 正常流程

- [ ] 账号 A 在画布内「导出画布」，得到 `.canvas.json`，进度弹窗正常关闭
- [ ] 账号 B 在画布列表「导入画布」选该文件：新画布出现，标题带「（导入）」
- [ ] 对比：节点、连线、分组、提示词、参数、选中的那一版结果、素材（图片和视频能打开）都一致
- [ ] 角色卡：B 名下新建了角色卡；重名时自动改名（结果弹窗里有计数）
- [ ] `@` 引用的节点关系还在
- [ ] 隔离：在 B 的导入画布里改节点、删节点、删画布，A 的原画布不受影响；反过来也一样

### B2. 异常与边界

- [ ] 导入被改坏的 JSON / 非 JSON 文件：提示文件不合法（30005），不产生新画布
- [ ] 导入版本号过高的文件：提示版本过高（30006）
- [ ] 超过 10 MB 的文件：提示超限（30007）
- [ ] 在原账号删掉一张素材后再导出：导出成功，报告里「跳过素材」计数正确，导入后该素材节点为空
- [ ] 导出 / 导入过程中点「取消」：能取消，不留半成品画布和孤儿素材
- [ ] 同一个文件连续导入两次：得到两张独立画布，素材不会重复占用异常空间

## C. 部署与升级（上线前，我没在真实环境验证过）
