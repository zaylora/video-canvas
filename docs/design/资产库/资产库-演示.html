资产库设计演示

把「生成历史」放进资产页，再加一个个人资产库，画布里用弹框引入

现在资产页的生成历史是样例数据，画布里的「画布素材」只是当前画布的侧边栏。这次改成：资产页一处看到所有生成结果（首页对话 + 全部画布），旁边多一个可以建文件夹、上传素材的个人资产库，画布里点开一个弹框就能从两处挑素材放上画布。历史是自动的流水，资产库是你自己整理的；删除只是把素材移出资产库，不动文件，画布里已经用上的不受影响。

阅读说明。本页对应 Markdown 设计文档《资产库.md》；设计尚未实现，原型的数据全在内存里，刷新复原，不调用任何真实服务。原型里的模型名、提示词、耗时、文件大小上限都是示意。界面的现状描述来自读代码，没有在浏览器里实测。

设计：历史和库分开——历史是流水、不要用户管；库是整理，只收用户挑的。放弃了「生成物自动进库」（Runway 式），因为库会被生成物淹没，也和你定的「上传为主」冲突。

三个地方分别做什么

它们读的是同一批素材，区别在于谁来整理、能不能改。

生成历史
只读 · 自动不提供删除

首页对话 + 所有画布的生成结果合并，按时间倒序；可按来源、时间、排序筛选，按提示词搜索。

个人资产库
用户整理只有一层文件夹

上传的素材 + 你加入的生成结果。可新建文件夹、上传、移动、移出；删文件夹会把里面的素材一并移出。

画布里的资产库弹框
两个来源一次最多 20 个

替换原来的侧边栏。多选后确认，每个素材建一个节点；入口是底栏按钮和「添加节点」菜单里的「从资产库添加」。

想复用上周另一张画布里生成的图时，会发生什么

四步，没有离开当前画布；注意被引入的是素材本身，不是复制。

  1. 点底栏「资产库」弹框打开；画布只读时按钮禁用并写明原因
  2. 切到「生成历史」→ 图片 → 时间选「近 7 天」→ 筛选选那张画布也可以直接搜提示词
  3. 勾选 1 到 20 个，点「确认」0 个时「确认」禁用
  4. 节点出现在落点附近横向最多 4 列，一次撤销全部移除；画布照常自动保存
边界：删除不等于清理存储。
  • 从资产库删除素材或文件夹，只是去掉归属，文件仍在存储里，画布节点继续正常显示。
  • 所以没有被任何画布引用、又被移出库的上传素材会一直占着空间；存储回收放在后续阶段。
  • 生成历史本期不提供删除。

这条「逻辑删除」是我对你「画布中的素材不受影响」的解读，已列入 Markdown §11.3 默认值；如果你要物理删除，需要先加引用检查，工程量明显变大。

谁归属谁

归属关系决定了「删除」的语义。

对象允许的关系为什么
素材 → 资产库同一用户最多一条归属，要么在根目录，要么在某一个文件夹只有一层文件夹；换位置用「移动到…」，不需要「多处出现」
文件夹 → 素材一对多，文件夹删除时归属行一起删你的决定：里面的素材一并移出，不退回根目录
资产库归属 → assets 行只引用，不复制；移出库不动 assets 与存储文件画布节点存的是 assetId，必须一直有效
生成历史 → 任务一个任务可对应多个素材（每个素材一张卡）提示词与模型取自任务；canvas_project_id 为空视为首页对话（推断）

数据模型

新增两张表和一个索引；assets 本身不改字段。

asset_folders 表
idbigint 主键；对外用十六进制串（idcodec.ID）
user_idbigint not null
namevarchar(30) not null，1–30 字；唯一索引 (user_id, lower(name))
created_at / updated_attimestamptz
asset_library_items 表
idbigint 主键
user_idbigint not null
asset_idbigint not null；唯一索引 (user_id, asset_id)
folder_idbigint null；null = 根目录；索引 (user_id, folder_id, created_at desc, id desc)
created_at加入时间，库内默认倒序

assets 新增索引 (user_id, source, kind, created_at desc, id desc)，给生成历史分页用。是否用外键级联：待实现时核对（默认在事务里先删归属行再删文件夹）。

接口

都在已登录分组下，按当前用户隔离；别人的 id 一律 404。

方法与路径说明与业务错误
GET /assets/generated生成历史。参数 kind（必填）、source（all / conversation / canvas）、canvas_id、created_from（RFC3339，客户端按本地时区算「今天 / 近 7 天」）、order、q、cursor、limit（默认 40，最大 100）。排除试跑任务。错误：参数非法 400
GET /asset-folders全部文件夹（≤100，不分页），含 item_count
POST /asset-folders{name}，201。错误：名称不合法 400、重名 409、数量达上限（100）409
PATCH /asset-folders/:id{name}。错误同上，不存在 404
DELETE /asset-folders/:id删文件夹及其归属行，返回 {removed}；不动 assets。不存在 404
GET /asset-library/itemsfolder_id（root 默认 / id / all）、kind、q（文件名）、cursor、limit。有搜索词时前端传 all。文件夹不存在 404
POST /asset-library/items{asset_id, folder_id?}，加入资产库；已存在则 200 返回现有归属（幂等）。素材不属于该用户或不存在 404；文件夹不存在 404
PATCH /asset-library/items/:id{folder_id: id | null}，移动。不存在 404
DELETE /asset-library/items/:id移出资产库，不动 assets 与文件。不存在 404

核心流程伪代码

// 后端：生成历史查询（提案）
SELECT a.*, t.input_json, t.config_snapshot, t.model_id, t.canvas_project_id
FROM assets a JOIN generation_tasks t ON t.id = a.task_id
WHERE a.user_id = :uid AND a.source = 'generated' AND a.kind = :kind
  AND t.is_test = false
  AND (:source = 'all' OR (:source = 'conversation' AND t.canvas_project_id IS NULL)
                       OR (:source = 'canvas' AND t.canvas_project_id IS NOT NULL
                           AND (:canvas_id IS NULL OR t.canvas_project_id = :canvas_id)))
  AND (:created_from IS NULL OR a.created_at >= :created_from)
  AND (:q = '' OR t.input_json->>'prompt' ILIKE '%' || :q || '%')
  AND (a.created_at, a.id) < (:cursor_at, :cursor_id)      -- order=desc；asc 反向
ORDER BY a.created_at DESC, a.id DESC LIMIT :limit + 1;
-- 之后一次 IN 查询补 library_item_id；画布标题批量查，已删除的标 deleted

// 后端：删除文件夹（提案）

COMMIT;  -- assets 行与存储文件一概不动

已确认的决定

  1. 生成历史合并首页对话和所有画布的生成结果：满足「画布里的生成历史也要在资产页」；原先「只读对话记录」的规划作废。
  2. 资产库以上传为主，生成结果可「加入资产库」：不复制文件，同一条素材多一个归属。
  3. 文件夹只有一层。
  4. 画布弹框有两个来源（个人资产库、生成历史），删除旧侧边栏。
  5. 确认后每个素材建一个节点。
  6. 去掉「文档」标签。资产页和弹框都不放。
  7. 删除规则：画布里已用的素材不受影响；删文件夹时里面的素材一并移出；生成历史不提供删除。
  8. 只有资产页和弹框里上传的才算进资产库；画布节点上传和首页参考图上传不自动进库。
  9. 「筛选 / 时间 / 排序」启用，给出明确选项。
  10. 弹框附加：「添加节点」菜单加「从资产库添加」；弹框内可直接上传。「按拉线上下文限制类型」和「拖拽归档」未选，已搁置。
  11. 主文档已回写：弹框内上传后自动勾选；「删除」按逻辑删除理解、需要回写《首页生成与对话》§6.5 与 §10.2，见 Markdown §11.3。
