后台助手 · 聊天框原型 v2 · 2026-11-02 · 提案，未实现

重做的聊天框：像一个配置工具，而不是一个聊天机器人。颜色和半透明面板沿用后台真实令牌（.admin-theme、--chrome）。 对话按时间线排成记录，助手的执行步骤写成可折叠的日志，改动用评审式变更单展示。数据都在内存里，刷新即复原；助手的回复用定时器模拟，不是真实调用。 下面的按钮会把示例指令填进输入框，按 Ctrl Enter 或点「发送」执行。

去掉了什么闪光图标、紫色渐变、对话气泡、快捷指令胶囊、打字光效、「我是你的 AI 助手」欢迎语。这些都在提醒「这是 AI」，对完成任务没有帮助。
换成了什么时间线记录（头像 + 名字 + 时间），日志式执行步骤（等宽字体、耗时右对齐），评审式变更单（字段 / 当前 / 变更后），带快捷键提示的发送按钮。
和项目规范的关系面板用清透 chrome 令牌、圆角胶囊入口（见 coding-standards 6.1）；界面里不加操作说明小字，空状态只放图标、标题和最近会话（见 6.2）。

点一行就把它设为助手的上下文，输入框里会出现对应的引用标签。变更单应用后，这张表即时刷新，改动的行闪一下。
变更单为什么做成表格调价一次就是十几行数字，表格能逐行对齐比较「当前」和「变更后」。删除线和绿色只用在数值上，不把整行涂色。有问题的行照样显示但不能勾选，让人看到助手哪里没做对。
执行步骤为什么默认折叠管理员关心的是结果和变更单，过程只在需要排查时展开看。运行中只显示一行「第 3/6 步」加一条细进度条，不用会动的文字特效。
待审核时输入框不锁输入框上方固定一行提示「变更单 CO-xxxx 待审核」，点一下就跳回那张单。这时仍然可以继续补充要求，助手会作废旧单、重新出一张。
