短剧工作室演示

上传一份剧本，一路做到每集成片

首页侧栏新增「短剧工作室」。用户上传剧本或小说，系统按固定流水线一步步产出大纲、分集剧本、角色/场景/道具资产、分镜片段和视频；每一步都能审阅、修改、单独重试。资产就是这部短剧专属画布上的节点，列表只是另一种看法。拆解过资产的集，剧本会锁定。分三期交付。

阅读说明。本页对应 短剧工作室.md（准绳）。项目现状来自 2026-10-28 的代码扫描并抽查；竞品行为只来自需求文档里的即梦截图，没有实际操作；所有界面、接口都是提案，尚未实现。原型里的数字、积分、耗时都是示意。

设计：文本步骤（研读、大纲、剧本、拆解、分镜）都是固定提示词模板 + JSON 输出 + 校验的后台任务，不交给 Agent 自由发挥——长剧本下更稳、好计费、能单步重试。右侧短剧助手（三期）只负责对话式修改，复用画布 Agent。
回退与兜底：模型输出不合法自动重试 1 次，仍失败就停在这一步（错误码 67008），可重试、不扣积分；单集失败只重试那一集；刷新或断线后靠任务对账恢复进度；项目选的文本模型被停用时，回落到后台「文本」类别第一个启用的模型；一个都没有时流水线按钮禁用。任何一步都可以跳过 AI，直接手写或在画布里手建。

用户对第 2 集做资产拆解时，会发生什么

这是最容易出意外的一步：要花积分、会锁剧本、会和第 1 集已有的资产合并。

  1. 点「资产拆解」，弹出确认框比例必选（第一次拆解时定）；集数默认第一个未拆解的集；已锁定的集置灰写「已拆解」；显示积分估算。
  2. 确认 → 排队 breakdown 任务同一部剧同时只能有一个文本流水线任务，其他流水线按钮置灰。
  3. 模型输出角色（含造型）、场景、道具和出现集数校验不过自动重试 1 次。
  4. 和已有资产按名称 / 别名合并第 1 集已有的「林川」不新建，只把 2 加进出现集数；新角色才建角色卡 + 节点。
  5. 自动接「资产提示词」任务只给新资产写图片提示词；结果由后端写进短剧画布并推送，列表同时出现。
  6. 第 2 集剧本变只读编辑器和助手都不能再改。
边界：拆解后该集剧本不可再改。
  • 发现错别字也改不了；需要改只能等将来「解锁」功能（已搁置，见 Markdown §11.2）。
  • 合并只按名称 / 别名；模型把同一人起了两个名字时会出现重复资产，需要用户在画布里删掉一个。
  • 拆解期间用户在画布里同时改节点，后端写入走同一把 revision 锁，前端三方合并。

交付时要在确认框里写清：「拆解后这些集的剧本将锁定，将消耗约 N 积分」。

流水线每一步吃什么、吐什么

每个文本步骤都按「输入变量 → 提示词正文 → 输出结构 → 校验规则」整理（需求文档 4.3 的建议）。左边选一步，右边看它的输入、输出、失败时怎么办。可以改「范围」看积分估算怎么变。JSON 字段是提案，积分算法是示意。

// River job: drama_step（提案）
func RunStep(job) {
  model := resolveTextModel(drama.TextModelID)  // 不可用 → 回落「文本」类别第一个；没有 → 67007
  for chunk in split(job) {                     // scripts 按集；analyze 按章节分块
    tpl  := prompts[job.Step]                   // 输入变量 → 正文 → JSON Schema → 校验
    out, err := callText(model, tpl.Render(vars(chunk)))
    if !tpl.Validate(out) {                     // 自动重试 1 次，带上校验错误
      out = callText(model, tpl.Repair(out, err))
      if !tpl.Validate(out) { fail(67008); return }  // 不扣积分
    }
    persist(job.Step, chunk, out)               // 写库 / 写画布
    progress(job, chunk)                        // 推 drama.job
  }
}

已确认的决定

  1. 全流程设计，三期交付：剧本 + 资产 → 分镜 + 视频 → 助手 + 合成。
  2. 固定流水线 + 助手辅助：稳定、好计费、可单步重试。
  3. 资产以短剧画布节点为准：列表是视图，天然同步。
  4. 输入 = 剧本或小说文件 + 粘贴文本，不做一句话创意。
  5. 风格库 = 内置精选 + 自定义，后台可配置放后续。
  6. 合成 = 前端连播预览 + 服务端 ffmpeg。
  7. 入口 = 侧栏一级 + 全屏工作台。
  8. 角色复用角色卡，扩展造型；去掉名称唯一与主图必填。
  9. 短剧助手复用 Agent，加短剧工具。
  10. 拆解后该集剧本锁定（同即梦）。
  11. 片段 = 参考生视频，首帧可选。
  12. 文本模型跟随后台「文本」类别，默认第一个，用户可在项目里换。
  13. 已搁置：后台风格库、一句话创意、拆解后解锁（见 Markdown §11.2）。
