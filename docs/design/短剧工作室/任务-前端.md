## B 段：短剧页面（一期）

**前提**：A 段已完成。后端可能尚未就绪，API 层严格按契约写；页面开发时可在 `web/src/api/drama/` 旁加一个**仅开发用**的 mock 开关（默认关闭，不进生产路径），或直接依赖契约写好类型和单测。

范围（对照原型）：

1. **入口与路由**：
   - 侧栏 `NAV` 加「短剧工作室」，带 New 角标，图标用 lucide `Film`，路由 `/drama`，放在 `HomeLayout` 下。
   - `/drama/:id` 全屏工作台，与 `/canvas/:id` 同层级。
2. **API 层** `web/src/api/drama/`：
   - 契约 §3 全部接口，加类型和 mapper。
   - 错误码处理按契约 §8。
   - WS 事件 `drama.job` 接入现有 ws 层。
3. **列表 / 新建页** `/drama`：
   - 上传卡支持上传 / 粘贴两个 tab，可以拖入文件。
   - 底部的题材、画风、比例、集数和时长都是浮层选择。
   - 「我的短剧」列表。
   - 空内容、格式错误都要有提示（67002 / 67003）。
4. **工作台** `/drama/:id`：
   - 左导航：剧本 / 资产 / 分集。分集一期只放「二期上线」的占位页。
   - 顶栏：项目名可改、保存状态、画风、比例、文本模型下拉（列 `kind=text` 模型，第一个标默认）。
   - 右栏「进度」：任务卡、进度条、失败后重试。用 WS 加挂载时对账 `GET /jobs?status=active`。
   - 右栏「助手」tab 只放三期占位。
5. **剧本区**：
   - 目录：大纲 / 人物 / 第 N 集，带状态图标。
   - 研读中显示步骤加骨架屏。
   - Markdown 编辑复用文本节点的 Tiptap Markdown，自动保存，带 `revision`，409 弹冲突提示。
   - 锁定集只读，带黄色提示条。
   - 底部「下一步」浮条：生成分集剧本 / 资产拆解。有进行中任务时禁用，并写明原因。
6. **资产拆解对话框**：
   - 比例必选；已有锁定集时比例固定不可改。
   - 集数多选：已锁定的、没有剧本的都禁用。
   - 积分估算走 `POST /estimate`。
   - 有锁定提醒。
7. **资产区**：
   - 列表 ⇄ 画布切换。
   - 列表：类型 tab（角色 / 场景 / 道具 / 文本 / 图片 / 视频 / 音频）、集数筛选（全集 / 第 N 集 / 未分类）、多选批量生成、卡片各状态、「在画布中定位」。
   - 画布：用 A 段的编辑器组装短剧资产画布，加载 `canvas_id`。具体包括：
     - 资产库浮窗
     - 节点功能区「出现集数」（读写 `data.drama`）
     - 选中节点下方复用 `TaskPromptPanel`；角色节点也要能生成图片，生成成功后若角色卡无主图，`PATCH /characters/:id` 写回主图
     - 新建节点默认「全集」
     - 后端推来的 `canvas.patch` 照常三方合并
   - 列表和画布读同一份节点数据。
8. **角色卡适配**（契约 §5）：
   - 主图可空时，卡片和节点显示「待生成形象」。
   - 去掉前端「名称唯一」的校验和提示。
   - 类型加上 `drama_id`、`look_name`、`voice_prompt`。
9. **画布列表**：前端不用改（后端过滤），确认首页和画布列表不出现短剧画布即可。

**测试**：至少覆盖 API mapper、错误码映射、集数筛选与「全集 / 未分类」语义、资产合并后列表计数、锁定集只读判定、下一步浮条状态判定、任务对账合并逻辑。
