# 短剧工作室设计：从剧本到分集成片的一站式工作台

> - **范围**：首页侧栏新增「短剧工作室」。用户上传剧本或小说（或粘贴文本），系统按「研读 → 大纲与人物 → 分集剧本 → 资产拆解 → 资产生成 → 分镜脚本 → 片段视频 → 合成整集」的流水线推进；工作台内有剧本、资产库（列表 + 短剧画布两种视图）、分集视频三个区，右侧是短剧助手。不含：多人协作、剧本版本历史、PDF 解析、TTS / 音色克隆、字幕与配乐生成、多轨剪辑。

## 1. 设计摘要

- **问题**：做一部 AI 短剧要经过剧本、角色/场景/道具、分镜、视频、拼接多道工序。现在用户只能在无限画布里手工搭：自己拆剧本、自己建节点、自己写每个镜头的提示词，集数一多就乱，角色也容易前后不一致。
- **目标**：
  1. 上传一份剧本或小说，能一路推进到每集可播放的成片。
  2. 每一步的结果都能审阅、修改、重试，不是一次性黑盒。
  3. 资产按集归属，跨集复用同一个角色/场景，保证一致性。
- **推荐结论**：
  - **固定流水线 + 助手辅助**：每个 AI 步骤是一个后台任务（固定提示词模板，输出 JSON，校验后落库），可重试、可审阅；右侧短剧助手（复用画布 Agent）做对话式修改。
  - **资产以短剧专属画布的节点为准**：每部短剧自带一张画布（复用现有画布引擎、`revision` 保存）；资产列表只是按类型 / 集数过滤节点的另一种视图，天然同步。
  - **角色复用角色卡**：短剧角色就是带 `drama_id` 的角色卡，加「造型」名；去掉名称唯一和主图必填两条规则。
  - **片段视频走参考生视频**（omni），关键帧可选；片段生成复用现有 `generation-tasks`，`node_id` 用 `seg:{片段id}` 前缀。
  - **合成整集**：前端连播预览，服务端 ffmpeg 合成。
  - **三期交付**：一期剧本 + 资产；二期分镜 + 视频工作区；三期短剧助手 + 时间线连播 + 合成整集。

### 2.2 设计约束

1. 画布保存靠 `revision` 乐观锁；后端写短剧画布必须走同一把锁，并推 `canvas.patch`，否则前端会冲突。
2. 生成任务要求 `node_id`；没有画布节点的生成（片段）需要前缀约定（同 `rec:`）。
3. 一部短剧可能几十集、几十万字，单次模型请求放不下，流水线必须能按集分批。
4. 资源查询一律带 `user_id` 隔离。
5. 项目约定：先写失败测试；后端测试放 `backend/internal/tests/`，前端放 `web/src/tests/`；改代码开 worktree。

### 2.3 当前缺口

- 没有「短剧项目 / 集 / 片段」实体；没有流水线任务；没有资产的集数归属；没有资产面板拖入；没有视频拼接；没有 docx 解析；角色卡规则与短剧冲突（名称唯一、主图必填）。

## 3. 用户与场景

- **用户**：做 AI 短剧的个人创作者或小团队里的制作者，手上有现成剧本或网文，熟悉画布基本操作（推断：来自需求文档和即梦截图的流程）。
- **触发场景**：
  1. 拿到一份 16 集剧本，想快速出前两集样片。
  2. 一部网文想改编成竖屏短剧，先要大纲和分集。
  3. 已有剧集里某个角色形象不满意，重生成后希望所有集自动用上新形象。
- **主任务**：上传 → 审剧本 → 拆资产、生成形象 → 生成某集分镜脚本 → 逐片段生成视频 → 合成整集。
- **成功指标（提案）**：
  - 一份 ≤ 3 万字、≤ 20 集的剧本，从上传到拿到第 1 集全部片段视频，用户手动操作不超过 15 步（不含审阅修改）。
  - 同一角色在不同集的片段生成请求里，引用的是同一张角色卡的同一组形象图（可用接口日志验证）。
  - 任一流水线步骤失败可单独重试，不需要从头再来。

## 5. 设计原则

1. **每一步都有落地的中间产物**：大纲、剧本、资产、分镜都是能看、能改、能重试的数据，不是一次性黑盒（来源：用户选「固定流水线」，§11.1-2）。
2. **一份数据，多种视图**：资产只存在短剧画布里，列表是视图；片段只存在片段表里，时间线是视图（来源：§11.1-3）。
3. **复用已有能力，不造平行体系**：画布引擎、生成任务、角色卡、Agent、ffmpeg 全部复用（来源：项目约束 §2）。
4. **拆解与生成分开**：先定「需要哪些资产、出现在哪些集」，再写图片提示词（来源：需求文档 4.3、drama-skills）。
5. **花积分前先告知**：每个会扣积分的批量操作先显示估算（来源：即梦拆解确认弹窗）。
6. **按集推进，任何一集可单独重来**（来源：约束 §2.2-3）。

## 6. 推荐方案

### 6.1 信息架构

```
侧栏「短剧工作室」 /drama
 ├─ 项目列表 + 新建（上传 / 粘贴 + 题材、画风、比例、集数、单集时长）
 └─ 工作台 /drama/:id   （全屏，不带首页侧栏）
     ├─ 顶栏：项目名 · 风格库 · 比例 · 文本模型 · 积分
     ├─ 左竖导航：剧本 | 资产 | 分集视频
     ├─ 主区（随左导航切换）
     │   ├─ 剧本：目录（大纲 / 人物 / 第 N 集）+ 正文编辑
     │   ├─ 资产：[列表 | 画布] 切换；列表按 类型 tab × 集数筛选
     │   └─ 分集视频：集卡片网格 → 点进「片段工作区」 /drama/:id/ep/:no
     │        片段工作区：左资产库 · 中片段提示词 · 右预览 · 底片段条（三期升级为时间线连播）
     └─ 右侧短剧助手（三期；一、二期位置放「流水线进度」）
```

- **入口**：侧栏 `NAV` 加「短剧工作室」（`Film` 图标，`/drama`），首页 tab 不动（§11.1-7）。
- **短剧画布不出现在普通画布列表**：`canvas_projects` 加 `drama_id`，画布列表与侧栏最近画布过滤掉 `drama_id` 非空的行（提案）。

### 6.2 主流程

1. **新建**：上传 txt / md / docx 或粘贴文本（≤ 30 万字，默认值）；选题材（12 类，可空）、画风（11 种或自定义一段描述）、比例（可后改，拆解前必选）、目标集数（1–100，默认「自动」）、单集时长（30–180 秒，默认 60）。提交 → 建短剧 + 建短剧画布 → 自动排队「研读」。
2. **研读（analyze）**：判断剧本 / 小说；剧本按已有分集或场次整理，小说按章节建索引；抽人物表与梗概。完成后自动排队「大纲」。
3. **大纲（outline）**：故事大纲、人物传记、每集梗概（标题 + 梗概 + 结尾钩子）。完成后用户在剧本页审阅，可改。
4. **分集剧本（scripts）**：用户点「生成分集剧本」（默认全部，可勾选）；每集一个子任务，串行，带上一集结尾作为衔接上下文；单集失败只重试该集。若来源是已分好集的剧本，研读后直接产出分集剧本，跳过 3–4 的生成，只做格式整理（推断：省积分）。
5. **资产拆解（breakdown）**：工具栏「资产拆解」→ 确认弹窗：比例（必选）、解析范围（勾集数，默认第一个未拆解的集）、积分估算、提示「拆解后这些集的剧本将锁定」。任务输出角色（含造型、出现集、音色描述）、场景（含出现集）、道具（含出现集），与已有资产按名称 / 别名合并（已有则补集数，新的才新建）。随后自动接「资产提示词（asset_prompts）」为每个新资产写图片提示词。结果由后端写进短剧画布（角色卡 + 角色节点、场景 / 道具图片节点），所选集标记为已锁定。
6. **资产生成**：列表多选「批量生成」或画布里逐个生成，走现有图片生成；角色节点生成的图自动设为该角色卡主图（无主图时）。音色：填描述 + 上传参考音频（有音频模型时可「试听生成」，默认值）。
7. **分镜脚本（storyboard）**：分集视频页集卡片「生成脚本」→ 任务输出该集片段列表：每片段 ≤ 15 秒（默认值，取所选视频模型时长上限），含 1–N 个分镜（时长、景别、运镜、动作、对白），正文里用 `@[资产名](节点id)` 嵌入资产。
8. **片段视频**：片段工作区里改提示词、@ 或拖入资产 → 「生成」：解析 @ 得到参考图（角色主图 + 补充图、场景、道具）与参考音频（角色声音），按所选视频模型 `omni` 方式提交；片段可选「生成首帧」，有首帧后改走 `i2v`。每个片段保留多次生成结果，选一个作为「采用」。
9. **合成整集（三期）**：片段条按顺序连播预览；「合成整集」起后台任务，ffmpeg 把各片段的「采用」视频统一分辨率后拼接，产物存为素材，可下载。

### 6.3 关键交互

- **剧本页**：左目录（大纲 / 人物 / 第 1…N 集，已锁定集带锁图标），中间 Markdown 编辑（复用文本节点的 Tiptap Markdown），失焦或 1.5 秒无输入自动保存（默认值，同画布节奏）。底部浮条显示流水线下一步建议（例：「剧本整理完毕，下一步资产拆解」+ 积分 + 按钮）。
- **资产 · 列表**：类型 tab = 角色 / 场景 / 道具 / 文本 / 图片 / 视频 / 音频（计数），右上集数筛选（全集 / 第 N 集 / 未分类）；顶部提示条「有 5 个角色还没有形象图」+ 多选批量生成；卡片 = 缩略图 + 名称 + 状态（待生成 / 生成中 / 已生成 / 失败）；点卡片 → 切到画布并定位到节点。
- **资产 · 画布**：就是短剧画布（同无限画布交互）；左侧浮动资产库面板（按集 / 未分类筛选），节点功能区多一个「出现集数」多选；画布里新建的资产默认「全集」。
- **节点生成面板**：选中节点时，节点下方出现和无限画布完全相同的生成面板（直接复用 `TaskPromptPanel` / `NodePromptInput`）：引用条（连线、上传、`@` 引用的参考素材 + 放大编辑）、提示词（可 `@`，字数计数）、工具行（模型 ▾、参数 ▾、预设、积分、生成按钮，⌘↵ 提交）。短剧里只多做三件事：
  1. 提示词默认填入 `asset_prompts` 步骤写好的资产提示词，用户可改。
  2. 预设默认按资产类型选：角色「角色三视图」、场景「场景参考图」、道具「道具参考图」（沿用无限画布的 `PresetPicker`，用户可换）。
  3. 参数默认值：角色 3:4，场景 / 道具跟随项目比例。  
     选中节点时，上方功能条只保留「出现集数」「在列表中查看」，「生成」统一放在下方面板，不重复。
- **出现集数语义**：`episodes = []` 表示全集出现；`[1,2]` 表示只在 1、2 集；节点没有 `drama` 字段 = 「未分类」（画布里随手建的普通节点）。
- **分集视频页**：集卡片 = 缩略图 + 状态（待生成脚本 / 脚本已生成 / 生成中 / 已完成）+ 角色数 / 场景数 + 「生成脚本」；「新增一集」「批量生成脚本」。
- **片段工作区**：
  - 左资产库：默认当前集，可切全集；按角色分组显示造型。
  - 中提示词区：沿用画布节点提示词交互（Tiptap + @）；`@` 候选 = 本剧全部有 `drama` 字段的资产节点；从左侧拖资产卡到提示词里插入 chip。
  - 右预览：当前片段「采用」的视频；多次结果可左右切换并「设为采用」。
  - 底片段条：片段卡（缩略图、序号、时长），点选切换中间内容；拖动排序；「+」新增空片段；「批量生成」选多个片段一起提交。
  - 顶栏：视频模型、分辨率、比例（默认取项目比例）。


## 7. 状态与异常

| 对象                        | 状态                                                                                                                            | 迁移与界面                                                                           |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 短剧项目 `status`             | `analyzing → outlined → scripting → ready`                                                                                    | 由流水线推进；`ready` 表示至少一集有剧本                                                        |
| 流水线任务 `drama_jobs.status` | `queued → running → succeeded / failed / canceled`                                                                            | 推送 `drama.job`；页面挂载 / 重连时 `GET /dramas/:id/jobs?status=active` 对账；失败显示原因 + 「重试」 |
| 集 `drama_episodes`        | `script_status`：`empty / generating / ready / failed`；`locked`：bool；`storyboard_status`：`empty / generating / ready / failed` | 锁定后剧本、梗概只读，助手也不能改                                                               |
| 资产节点                      | 沿用节点 `status`：`idle / running / done / error`                                                                                 | 列表卡片显示同一状态                                                                      |
| 片段 `drama_segments`       | `idle / running / done / error`，`outputs[]` + `chosen`                                                                        | 生成走 `generation_tasks`，`node_id = seg:{id}`                                     |
| 合成任务                      | 同流水线任务（`step = compose`）                                                                                                      | 成功后集卡片显示成片                                                                      |

异常处理：

- **模型输出不是合法 JSON / 校验不过**：同一请求自动重试 1 次（带校验错误提示）；仍失败则任务 `failed`，错误码 67008，不扣积分（默认值：失败不扣，沿用生成任务失败不扣费的做法，实现时核对积分结算逻辑）。
- **同一短剧已有进行中的文本流水线任务**：再提交返回 67004，前端按钮置灰并提示「正在 X，完成后再试」。资产生成、片段生成不受此限。
- **前置未完成**：没有剧本就拆解、没有拆解就生成脚本 → 67006，按钮禁用并写原因。
- **剧本已锁定**：PATCH 锁定集返回 67005；编辑器只读并显示「已拆解资产，剧本已锁定」。
- **保存冲突**：集剧本用 `revision` 乐观锁，409 时弹窗「内容已在别处修改，重新加载 / 覆盖」，沿用画布冲突弹窗；短剧画布沿用画布现有冲突处理。
- **后端写画布与用户同时编辑**：拆解结果通过 `canvas.patch` 推送，前端三方合并（现有机制）；后端写入遇 `revision` 冲突时重读重放（提案，需实现时核对 Agent 写画布的重试策略）。
- **文本模型被停用**：项目上记的模型不可用时回落到「文本」类别第一个启用模型，并提示一次；类别里一个都没有 → 67007，流水线按钮禁用。
- **片段引用的资产已删除**：chip 显示失效样式，生成前提示「有 N 个引用已失效」，允许继续（只是少了参考）。
- **模型不收参考音频**：只用形象，提示「声音未生效」，不阻断（沿用角色卡做法）。
- **刷新 / 断线**：流水线任务和生成任务都在后端，刷新后对账恢复。
- **撤销**：剧本编辑用编辑器自身撤销；画布沿用画布撤销；流水线结果不提供「撤销」，靠重新生成（默认值）。
- **权限**：所有短剧资源按 `user_id` 隔离，别人的 ID 返回 67001（不存在）。

### 8.3 节点数据扩展（payload，不需要迁移）

```ts
// 短剧画布里的资产节点多一个 drama 字段；没有 = 未分类
data.drama?: {
  type: "character" | "scene" | "prop";
  episodes: number[];   // [] = 全集
  name: string;         // 资产名，列表展示与 @ 候选用
};
```

- 角色：`kind = character` 节点（`characterId` 指向带 `drama_id` 的角色卡），一个造型一张卡、一个节点；列表按卡的 `name` 分组。短剧画布里的角色节点额外带生成面板（复用 `TaskPromptPanel`，按图片节点处理：`kind = image` 的模型列表与 capabilities），成功后若卡无主图则写为主图，否则结果进 `outputs`，用户「设为形象」。角色卡已绑定的形象图、参考音频显示在面板引用条里。
- 场景 / 道具：`kind = image` 节点，`prompt` 为资产提示词。
- 文本 / 图片 / 视频 / 音频 tab 列的是画布里对应 `kind` 且带 `drama` 字段的节点（用户在画布里手动归类的）。

- 长输入：小说研读按章节分块（每块 ≤ 模型上下文的 60%，默认值），再汇总。
- docx：`archive/zip` 读 `word/document.xml`，按 `<w:p>` 分段取 `<w:t>` 文本。
- 合成：`compose` job 下载各片段采用的视频 → ffmpeg 统一到项目比例与最高分辨率（默认值：取第一段分辨率）→ `concat` → 存素材 → 写 `final_asset_id`。

### 8.7 前端模块

- 路由：`/drama`（在 `HomeLayout` 下）、`/drama/:id`、`/drama/:id/ep/:no`（全屏，同 `/canvas/:id` 层级）。

- 新增「从资产面板拖到提示词」：`dataTransfer` 带 `{nodeId, name}`，Tiptap 插入 mention（画布内的提示词区与片段工作区共用）。
- 片段生成复用 `resolveBindings` 思路：从 `@` token 取节点 → 角色卡展开为图片 + 音频、场景 / 道具为图片 → 按模型 `refs` 上限截断并提示。

### 8.8 画布抽象（一期前置，用户 2026-10-28 明确要求）

**结论**：短剧的资产画布和无限画布交互基本一样，但它们是两个不同的页面（`/canvas/:id` 与 `/drama/:id` 资产区）。实现时先把无限画布抽象成可复用的画布编辑器，两个页面各自组装；**不要复制一份，也不要在现有画布里加 `if (dramaMode)` 分支**。

**现状（事实）**：`web/src/pages/canvas/flow.tsx` 共 1088 行，把引擎和页面外壳写在同一个组件里。页面入口 `pages/canvas/index.tsx`（90 行）负责按路由 `id` 加载画布、加编辑锁、套 `ReactFlowProvider`。

| 归属 | 内容（`flow.tsx` 及周边现有代码） | 抽象后 |
| --- | --- | --- |
| 画布编辑器（共用） | 节点 / 连线状态与变更处理、`CanvasHistoryProvider` 撤销重做、`useCanvasPersistence` + `draftStore` 保存与草稿、`revision` 冲突弹窗、`useTaskBackfill` 任务回填、对齐线、编组（`group-*`）、多选、上传 / 粘贴 / 修剪 / 截帧 runner、节点类型（`canvas-node`、`video-node`、`text-node`、`character-node`、`director-node`）、`TaskPromptPanel` 生成面板、`NodeHistoryDialog`、`MediaLightbox`、`AssetPickerDialog` / `CharacterPickerDialog`、背景层、`use-canvas-shortcuts` | 抽成独立组件，例如 `components/canvas-editor/`；对外只收 `canvasId`、初始数据和扩展点 |
| 无限画布页面专属 | `chrome/` 下的左上栏、右上栏、底部工具条、`EmptyState`、`StatsBar`、`ShortcutsDialog`、Agent 入口与面板（`useAgentController`、`useAgentCanvasSync`）、页面标题 | 留在 `pages/canvas/`，通过插槽挂到编辑器上 |
| 短剧资产画布专属 | 资产库浮动面板（按集 / 未分类）、节点功能区「出现集数」、`data.drama` 读写、从列表定位节点、工作台顶栏 | 放在 `pages/drama/`，同样通过插槽和扩展点挂上 |

**扩展点（提案）**：
- **外壳插槽**：`ChromeZone` 各位置（左上 / 右上 / 左中 / 底部）由页面传入，编辑器只负责摆放。
- **节点功能区扩展**：页面可以给节点功能区追加按钮（短剧加「出现集数」）。
- **新建节点默认数据**：页面可以传一个钩子，在建节点时补默认值（短剧写入 `data.drama`、预填提示词 / 预设 / 比例）。
- **可用节点种类与添加菜单**：由页面决定（短剧画布可以不开 3D 导演台）。
- **对外命令**：编辑器暴露「定位到节点」「选中节点」「读取当前节点列表」，供资产列表视图使用；列表视图读的是同一份节点数据，不另存。

**顺序与验收**：
1. 先做纯重构，把 `flow.tsx` 拆成编辑器 + 无限画布外壳。**无限画布行为不变**，现有画布相关测试全部通过，再接短剧。
2. 短剧资产画布只写外壳和扩展，不复制引擎代码。
3. 后续无限画布的改动（新节点、生成面板、性能优化）两个页面自动同时获得。

这一步计入一期工作量，见 §10。

## 10. MVP 与后续

### 一期：剧本 + 资产

- 前置：画布抽象重构（§8.8），无限画布行为不变、相关测试全绿后再接短剧。
- 范围：侧栏入口、项目列表 / 新建、上传与粘贴（txt / md / docx）、风格库、analyze / outline / scripts / breakdown / asset_prompts 五个步骤、剧本页编辑与锁定、资产列表 + 短剧画布双视图、出现集数、批量生成资产、角色卡规则调整、流水线进度区（右栏占位）。
- 验收：
  1. 上传一份 16 集剧本（示例：需求截图里的 `_剧本原文.txt`，11.41 KB），得到 16 集剧本，每集可编辑并保存，刷新后仍在。
  2. 对第 1 集拆解：弹窗显示比例必选与积分估算；完成后第 1 集剧本只读；资产列表出现角色 / 场景 / 道具，计数与画布节点一致。
  3. 在画布里改一个资产名，切回列表立即看到；在列表点卡片，画布定位到该节点。
  4. 对第 2 集拆解，第 1 集已有的角色不重复新建，只追加出现集数。
  5. 批量生成 5 个角色形象，刷新页面过程中任务不丢，结束后角色卡有主图。
  6. 两部短剧都有「母亲」可以共存；个人资产页角色卡列表不出现短剧角色。
  7. 构造模型返回非法 JSON（测试桩），任务失败显示 67008，可重试，不扣积分。

### 二期：分镜 + 视频工作区

- 范围：分集视频页、storyboard 步骤、片段表与接口、片段工作区（资产库、提示词 @ / 拖入、预览、片段条排序 / 新增 / 删除 / 批量生成）、首帧可选、`seg:` 前缀结果回写。
- 验收：
  1. 第 1 集生成脚本得到 N 个片段，每段时长 ≤ 所选视频模型时长上限，提示词里的资产 chip 指向正确节点。
  2. 从左资产库拖一个场景到提示词，生成请求的参考图里包含它。
  3. 角色卡改了主图后，新提交的片段使用新图（实时引用）。
  4. 一个片段生成 2 次，可切换并设为采用；刷新后保留。
  5. 引用的资产被删除时，chip 显示失效、生成前有提示。

### 三期：助手 + 合成

- 范围：短剧助手（Agent 会话挂在短剧画布上，`mode = drama`，新工具 `drama_read`、`drama_update_episode`、`drama_run_job`、`drama_update_segment`，写操作需审批，`drama_run_job` 审批卡显示积分），时间线连播预览，compose 合成整集与下载。
- 验收：
  1. 对助手说「把第 3 集结尾改得更有悬念」，出现审批卡，同意后第 3 集剧本更新；对已锁定集提出修改，助手说明无法修改。
  2. 片段条播放从第 1 段连续播到最后一段，中间无明显黑屏（双缓冲）。
  3. 合成整集得到一个可下载的 mp4，时长 ≈ 各采用片段之和（误差 ≤ 1 秒）。
