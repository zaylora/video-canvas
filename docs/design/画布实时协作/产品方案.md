# 画布多人实时协作产品方案

## 目标

两到十人的创作小组可以在同一张普通画布上并行整理素材、修改提示词、排布镜头和审阅成果。不同人的内容改动在同一份作品中合并，每个人独立控制视角。成员知道谁在编辑、哪些改动已保存，以及何时需要处理冲突。

首个可发布版本面向普通画布网页端。版本范围、容量数字和权限默认值都是评审建议。实现细节和破坏性操作的逐项验证见[技术设计](技术设计.md)。现有共享语义见[共享画布一期方案](../共享画布/一期方案.md)。

## 权限与作品入口

| 角色 | 作品入口 | 可执行操作 | 首版生成权限 |
| --- | --- | --- | --- |
| 所有者 | 个人画布 | 编辑内容、查看和管理成员、发送副本、发起所有权转移 | 使用本人账号与额度 |
| 可编辑成员 | 共享给我 → 画布，标记「可编辑」 | 编辑已获授权的节点、提示词、连线和分组，主动退出协作 | 默认关闭，由所有者单独授权，使用发起人的额度 |
| 仅查看成员 | 共享给我 → 画布，标记「仅可查看」 | 浏览授权内容与媒体，主动退出共享 | 仅浏览结果 |

- 所有者在现有共享弹窗里选「仅可查看」或「可编辑」，也可直接调整已有成员的角色。「仅可查看」作为默认邀请权限。发送副本和转移所有权单独列出，其接收方以新画布的所有者身份从个人画布进入。
- 进入协作画布统一使用标准工作台。编辑成员自动收发内容变更。只读成员沿用个人刷新偏好，可在「不刷新」「定时刷新」「实时观看」之间选择。实时观看可在编辑功能稳定后上线，订阅由查看者主动开启。
- 降级后立即切换为只读状态，关闭编辑控件并处理未提交改动。撤权后提示「你已失去这张画布的访问权限」，清理该页面的受保护内容、待处理队列和预览。所有者管理成员时提示查看者可见的节点正文、提示词和媒体范围。

## 协作体验

| 场景 | 体验 |
| --- | --- |
| 同时进入画布 | 顶栏显示在线成员。远端光标和选区按颜色区分，可关闭光标展示。后续可从成员头像主动跟随，平移、缩放或按 Esc 退出跟随。 |
| 两人调整不同节点或字段 | 本地即时响应。提交后另一端原位更新内容，保留各自视角。 |
| 两人拖动同一个节点 | 提示「某人正在移动此节点」，移动预览作为临时状态显示。手势结束才提交位置。发生冲突时定位到节点，显示以服务器为准的位置，并允许用户基于当前版本再移动。 |
| 两人修改同一个提示词 | 编辑时提示对方正在修改。冲突时显示共同起点、当前已保存内容和自己的草稿，可比较后明确应用。支持字符级共同输入时再启用文本 CRDT。 |
| 断网或重连 | 顶栏区分「保存中」「已同步」「连接中断」「有冲突待处理」。可继续进行有限的本地编辑。恢复网络后校验权限、补齐版本、逐批重提。冲突及依赖该改动的草稿合并到待处理面板，独立编辑继续同步。 |
| 撤销与重做 | 撤销自己的最近一笔已确认编辑，包括删除节点、分组和连线。重做恢复实际撤销的操作。已被队友修改的字段或已被其他节点引用的结构按当前状态保留，并提示跳过项。 |
| 生成与回填 | 首版由所有者发起生成，成员看到共享节点结果与可公开状态。任务绑定启动时已确认的模型、参数和素材。运行期间可继续改节点，结束后按任务归属写回结果。后续多人试产时，成员可比较各自的结果，再选定主结果。 |

示例。甲拖动镜头节点时，乙可以修改同一节点的提示词，两项都可保存。若甲乙同时修改同一个提示词，则先提交的内容保存，后提交者保留草稿并处理冲突。

## 路线图

| 阶段 | 可交付体验 | 进入下一阶段的条件 |
| --- | --- | --- |
| 基础验证 | 特性开关内完成双账号会话、节点级操作、版本对账和撤权。逐个登记编辑器、CLI、Agent、生成回写和交付的写入口。 | 所有写入口完成兼容或隔离。跨实例、权限竞态和旧客户端写入测试通过。 |
| 首版内测 | 邀请可编辑成员，支持节点的创建、编辑、移动和删除，以及分组和连线。提供在线成员、光标、同字段冲突处理、短时断线恢复和个人撤销。首版可编辑节点以接入字段策略并完成验收的类型为准。 | 并发和权限用例通过。两人完成一次真实协作流程，并达到同步和恢复目标。 |
| 后续扩展 | 优先交付指定节点评论、提及和成员定位，支持异步交接。接着扩展实时观看、跟随视角、活动与版本历史。根据同字段冲突发生率决定是否启用提示词字符级共同编辑。 | 验证使用价值并完成对应的隐私、撤权和回档规则。 |
| 共同生成 | 允许所有者为指定编辑成员开通生成权限，使用发起者的额度，结果经授权进入共享画布。 | 扣费、素材生命周期、取消、撤权、重试和任务写回通过专项验收。 |

## 验收标准

#### AC01 授权与实时撤权

Given 所有者、可编辑成员、仅查看成员各在独立会话中。
When 编辑成员写入、查看成员尝试从任意入口写入，随后所有者降级或撤权。
Then 仅合法写入可提交，撤权生效后的读、写、重放和媒体请求均按新权限处理，在线页面及时降级或停止显示。

#### AC02 字段与结构冲突

Given 多人基于同一版本修改同一节点的不同字段、同一字段或互相关联的分组和连线。
When 操作以不同顺序到达，期间可能删除目标节点。
Then 独立字段均生效，同字段冲突显示草稿，结构操作满足图约束，删除后旧操作无法复活节点。

#### AC03 断线、重放与本地视角

Given 成员存在已发送未确认的编辑，随后断线或漏收事件。
When 重连、重复发送、收到乱序事件或因超出保留期收到快照。
Then 每笔编辑最多提交一次，可自动合并的操作接着提交，冲突草稿进入处理面板，内容达到服务器确认版本，视角沿用本地状态。

#### AC04 在线状态与只读偏好

Given 两位编辑者和一位查看者同时打开画布。
When 编辑者拖动或断线，查看者切换刷新模式。
Then 临时光标、选区和拖动预览按授权显示及过期，只有提交后的内容进入快照，查看者按所选模式更新。

#### AC05 异步写入与个人撤销

Given 所有者的任务仍在生成，成员同时修改节点，或另一个人已修改待撤销字段。
When 任务完成、Agent 或 CLI 发起操作，或用户撤销。
Then 支持的写入口走同一协作提交协议，隔离中的入口收到明确反馈。任务结果和撤销操作按字段条件应用，客户端收敛到服务器版本。

#### AC06 退役与恢复

Given 画布存在编辑会话、待同步改动或运行中的任务。
When 所有者发送副本、尝试转移，或运营关闭协作编辑。
Then 副本对应指定已提交版本，转移经写入和任务检查后原子交付，旧会话终止，回退时能读取最后确认版本。

#### AC07 共同生成的计费与素材

Given 后续启用共同生成，两名成员操作同一节点。
When 重复提交请求、并发生成、删除节点，或中间撤权。
Then 同一生成请求只触发一次，独立请求由各发起者计费。结果写回符合任务归属与节点状态。共享内容只暴露已授权的素材引用。

#### AC08 创作节点与素材入口

Given 所有者和可编辑用户打开同一张协作画布。
When 任一方新建或编辑分镜表、导演台、角色卡，或从工具栏、添加菜单上传或引入资产。
Then 双方在确认版本中看到相同的节点内容、附属素材和排布，刷新后可继续编辑。撤权后当前会话无法继续提交或读取共享素材。仅查看者维持只读。

#### AC09 复杂节点并发与素材归属

Given 两位编辑者从同一确认版本修改复杂节点，或在节点中绑定自己的素材。
When 他们提交、重试请求，或另一方已修改同一个字段。
Then 节点位置等独立字段可合并，同一份分镜内容、场景或角色资料冲突时保留本地草稿供处理。服务器校验嵌套素材的授权和类型，对成员私有素材生成画布所有者的独立副本，并向授权成员返回画布范围的地址。

#### AC10 自动拆分镜、角色 AI 音色与小镜

Given 所有者或已获生成权限的编辑成员在协作画布上操作。
When 他提交自动拆分镜、生成角色音色，或在小镜内编辑画布并批准生成。
Then 任务使用发起者的账户，服务器确认的改动通过协作版本同步。拆分镜追加保留运行期间新增的镜头，覆盖遇到同一分镜表的并行修改时提示失败。音色回填保留角色卡上并行修改的名称、外观和描述。

Given 成员的生成权限被收回，或协作会话代数已变化。
When 排队中的拆分镜开始运行，或该成员提交后续模型调用、编辑和审批。
Then 后续调用被拒绝，旧协作任务不能写入新会话。仅查看者不能提交这些任务。

#### AC11 手选媒体参考素材

Given 有编辑权限的成员在支持媒体参考的节点中选择、上传或移除图片、视频或音频参考。
When 保存后其他成员接收增量或重新进入画布。
Then 参考关系同步，授权成员可以预览素材。服务端校验素材权限和媒体类型，成员从画布授权地址读取。更新模型参数和更新手选引用分别进行冲突检查。

#### AC12 个人重做与结构恢复

Given 编辑者删除节点和分组，节点删除连带移除了连线，或编辑者连续撤销了自己的修改。
When 编辑者撤销或重做。
Then 按依赖恢复分组、节点和仍可连接的连线，重复重做按撤销栈顺序执行。保留队友已修改的字段和结构。本人确认一笔新编辑时清空自己的重做记录。

#### AC13 同节点生成多个候选

Given 所有者或获生成授权的成员在支持生成数量的模型中选择多个候选。
When 提交后各任务以不同顺序完成，或只有部分任务创建、执行成功。
Then 各成功结果陆续进入同一节点的版本历史，发起者可取消自己仍可取消的候选。候选沿用逐任务计费和提交幂等规则，私有任务标识不进入成员视图。

#### AC14 协作 AI 扩图

Given 有生成权限的编辑者对画布中的图片使用 AI 扩图。
When 合成参考图上传成功并确认输入版本。
Then 扩图进入协作任务链路，结果回填到扩图节点。同步队友的编辑时保留发起者本地的合成进度和错误提示，任务受理后以服务端状态为准。刷新后通过已确认的生成版本识别任务仍在运行。若合成素材已保存而提交失败，可以用同一参考重试。

#### AC15 媒体加工、个人收藏与视频参考

Given 成员在协作画布中编辑图片或视频节点。
When 保存图片标注、宫格切分、视频截帧或修剪结果。
Then 每份结果上传成功后与来源连线一起确认。其他成员的增量更新不会移除本地上传占位，失败格子留给发起者单独重试。

Given 所有者在共享成员菜单中开启默认关闭的「允许收藏素材」。
When 编辑成员将节点当前素材加入个人资产库。
Then 同一成员重复收藏同一份素材时复用已有条目。收回权限后，在途和新发起的收藏均须通过最新授权检查，先前确认入库的独立副本仍可使用。不具备授权时，工具栏提示联系所有者。

Given 编辑成员选择图生视频或全能参考，尚无当前方式可用的参考素材。
When 点击「添加参考图」或「添加参考素材」。
Then 通过当前模型支持的渠道从画布选择或上传适用的素材。成员能准备提示词和参数，发送生成任务需要独立授权。
