01先说结论

问题不是“没有对象存储”，是另外四件事

后端早就有 S3 兼容实现（minio-go），但它只能写在 YAML 里，而且存在四个会在生产上出事的缺口：

缺口 1 · 配不了

存储在启动时由 storage.New(cfg) 建一次，换存储 = 改 env + 重启。后台没有入口。

缺口 2 · 换不了

assets 只记了 storage_key，没记存在哪。一切换，旧素材全部 404。

缺口 3 · 会过期

私有桶返回 1 小时签名 URL，前端把它写进画布 payload 的 src。一小时后画布裂图。

缺口 4 · 兼容细节

OSS 只认虚拟主机寻址；COS 桶名带 APPID。现有配置都没体现。

03调研 · 三家存储

都兼容 S3，但差异就藏在细节里

阿里云 OSS 腾讯云 COS AWS S3 / 兼容 Cloudflare R2
Endpoint oss-{region}.aliyuncs.com cos.{region}.myqcloud.com s3.{region}.amazonaws.com {account}.r2.cloudflarestorage.com
寻址 只支持虚拟主机 虚拟主机 自动 path · region 固定 auto
桶名 普通 带 APPID：canvas-1250000000 普通 普通
签名 V4，不支持 aws-chunked V4 V4 V4
直传 需配 CORS · POST Policy（可限大小） 需配 CORS · 不支持 POST Policy，只能预签名 PUT
做法：差异收进厂商预设。管理员只填地域、桶名、密钥；OSS/COS 锁定虚拟主机寻址 + 强制 HTTPS；R2 只填 Account ID，直传方式自动换成预签名 PUT。

05已确认的决定

七个决定

# 决定 换来了什么
D1 多套命名存储 + 一个默认 切默认只影响新上传，旧素材原地可读
D2 稳定路由 /files/<key> + 302 payload 永不过期，前端零改动
D3 YAML 只留 local 对象存储唯一入口在后台
D4 中转 + 直传，按存储开关 中转兜底；大文件可绕开后端
D5 迁移放二期 MVP 收敛；被引用不可删
D6 继续用 minio-go 新增依赖 0
D7 定位字段锁定 防一次误改让全部旧素材 404

07素材访问

payload 只存稳定地址，签名留到最后一刻

GET /files/u12/202610/3f2a…e9.png
  ↓ storage_key → assets.storage_id
  ├─ 内置本地   → ServeContent（Range、长缓存）
  ├─ 公开 / CDN → 302 {public_base_url}/{key}

08上传

中转永远可用，直传按存储开启

PROXY后端中转（现状保留）
POST /assets，文件进后端
落临时文件 → 内容嗅探 → 探测宽高、时长
写入默认存储，插入行并记录 storage_id
无需 CORS；直传失败时也会自动降级到这里。
DIRECT浏览器直传（存储勾选“允许直传”）
POST /assets/upload-intents → 按服务商拿到 POST Policy 表单（S3/OSS/COS，桶侧限大小）或 预签名 PUT（R2，签入 Content-Length）
浏览器直接上传到桶
…/complete：后端 Stat 校验大小 + Range 读头部补做嗅探；不合法就删除对象
过期未 complete 的意图由 worker 清理对象

10规则与异常

会让旧素材失效的操作，从入口上就不提供

编辑（D7）

有素材引用后，🔒 服务商 / endpoint / bucket / 前缀 / region 锁定；
可改：名称、密钥、公开域名、签名有效期、直传开关。
换桶 = 新建一套。

删除（D5）

只能删“非默认、非内置、素材数 = 0”的存储；否则说明原因（“被 1,284 个素材引用”）。

设为默认

二次确认并写明影响；最近一次测试未通过时禁止。

权限与安全

admin 只读，super_admin 可写；Secret 只写不读、不进日志；写操作记审计；version 乐观锁防并发覆盖。

12范围

MVP 验收 · 二期

MVP

  • 从零配好并设为默认 ≤ 3 分钟，不重启
  • OSS / COS / S3 / R2 真桶分步测试通过
  • 填错密钥 / 桶 / 地域时，停在正确步骤并给出中文原因
  • 私有桶素材 7 天后仍能显示；视频可拖动
  • 切换默认后历史画布零裂图
  • 直传：超限被拒、伪造类型被删、CORS 失败自动降级

  • 素材迁移任务 A → B（进度、续传、校验）
